    Ajuda - Interpretacoes
    
  

  


    

      
O que é esta tela

      
É o diário de bordo do IA Command: cada mensagem recebida via WhatsApp gera um registro aqui com a pergunta original, a decisão tomada e a resposta enviada ao cliente. Use esta tela para entender por que uma resposta saiu errada, confirmar se o sistema está aprendendo e guiar melhorias de forma segura.

    


    

      
Coluna Pipeline

      

        
Chat-first (roxo)

        
A pergunta foi enviada ao modelo de IA no formato de conversa (chat multi-turn). O SQL foi gerado e validado pelo chat-service antes de ser executado.

      

      

        
Clássico (cinza)

        
Usou o pipeline de 3 fases legado (Fase 1 classificação → Fase 2 entidades → Fase 3 SQL). Indica que o chat-service falhou ou não estava disponível.

      

      

        
Reuso (azul)

        
SQL canônico gerado pela primeira empresa foi reutilizado para esta consulta. Nenhuma nova chamada à IA foi feita — apenas os sufixos de tabela foram adaptados.

      

      
O campo Turno chat indica em qual turno de conversa o SQL foi gerado. "Turno 1" é a primeira pergunta da sessão.

    


    

      
Abas do detalhe

      

        
Dados gerais

        
Resumo dos metadados: quando, quem perguntou, qual motor e pipeline foram usados, turno, duração, confiança, intenção detectada, dataset e contexto herdado. Inclui a pergunta original completa.

      

      

        
Query

        
Exibe lado a lado o SQL gerado/executado e a resposta completa entregue ao usuário. Se houve erro de validação SQL, aparece um aviso em vermelho antes do painel. Arraste a divisória para redimensionar.

      

      

        
Diálogo

        
Detalhes do raciocínio interno: trace do caminho percorrido, decisão estruturada em JSON e sinais técnicos (sinônimos, pipeline_origem, chat_turno, sql_validacao_erro).

      

    


    

      
Quando usar

      

        
Um cliente recebeu uma resposta errada ou estranha

        
Localize a mensagem pelo celular ou texto, abra o detalhe e veja exatamente o que o sistema entendeu. Verifique a intenção classificada, o dataset consultado e a resposta entregue.

      

      

        
O sistema está consumindo muitos tokens de IA externa

        
Filtre por Motor = "IA externa" e veja quais perguntas estão passando para fora. Se os termos usados ainda não têm equivalências cadastradas, adicione-as na tela de Equivalências.

      

      

        
Validar após cadastrar uma nova equivalência ou intenção

        
Faça uma pergunta real pelo WhatsApp, volte aqui e confirme se o Motor agora aparece como "IA interna" e a Confiança está alta.

      

    


    

      
Limpar log

      
O log cresce com o uso. Use o botão Limpar log para remover registros antigos por período ou apagar tudo da empresa. A ação é irreversível, mas fica registrada na auditoria do sistema.
