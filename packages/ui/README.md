# @iahub/ui

Componentes visuais compartilhados e genericos.

Nao colocar componentes com regra especifica de recrutamento neste pacote.

Estrutura atual:
- `frontend/css/iahub.css`: design system visual compartilhado
- `frontend/js/grid-group-panel.js`: painel generico de agrupamento de grids
- `frontend/js/rich-text.js`: helper generico de editor rico
- `frontend/js/audit-fields.js`: helper generico de campos de auditoria

As URLs publicas continuam como `/css/...` e `/js/...` durante a transicao.
