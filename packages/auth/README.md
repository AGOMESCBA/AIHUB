# @iahub/auth

Helpers compartilhados de autenticacao e sessao.

Este pacote deve conter apenas regras genericas reutilizaveis entre sistemas.

Estrutura atual:
- `frontend/js/auth.js`: helper de sessao, empresa ativa e injecao de controles globais no frontend

A URL publica continua como `/js/auth.js` durante a transicao.
