📱 WhatsApp para Currículos — Ajuda
📨 O que acontece quando um candidato envia o currículo?

O candidato envia um arquivo PDF pelo WhatsApp para o número configurado. O sistema processa automaticamente em 5 etapas:

1
Recebimento e validação do arquivo

O sistema verifica se a mensagem contém um arquivo do tipo documento. Outros tipos (imagem, áudio, texto) são ignorados. Se o arquivo não for PDF, o candidato recebe uma mensagem orientando a enviar em formato correto.

2
Extração do texto do PDF

O conteúdo textual é extraído do PDF. Se o arquivo estiver protegido ou for uma imagem escaneada sem texto legível, o candidato é notificado e o processo é encerrado para aquele envio.

3
Detecção de idioma e tradução

A IA identifica o idioma do currículo. Caso não esteja em português, o texto é automaticamente traduzido antes de prosseguir, garantindo que a análise funcione corretamente.

4
Verificação se é um currículo

A IA verifica se o documento enviado é de fato um currículo. Documentos que não forem identificados como currículo (contratos, comprovantes, etc.) são rejeitados e o candidato recebe uma mensagem explicativa.

5
Análise, salvamento e notificação

O currículo é analisado pela IA, os dados são extraídos (nome, e-mail, telefone, experiências, formação) e salvos no banco. O candidato recebe uma confirmação de recebimento e, se houver um número de destino configurado, o resumo do currículo é enviado para esse número.

⚠️ Tratamento de duplicatas

Antes de salvar, o sistema verifica se já existe um currículo com o mesmo e-mail ou telefone. Se houver, o candidato recebe uma mensagem perguntando se deseja atualizar o registro existente. Ele responde SIM (substitui) ou NÃO (mantém o anterior). O candidato tem até o próximo reinício do serviço para responder.

📦 Biblioteca utilizada: whatsapp-web.js

O sistema utiliza a biblioteca open source whatsapp-web.js — uma solução totalmente gratuita, sem custos de API. Ela funciona automatizando o WhatsApp Web em um navegador Chrome rodando em segundo plano no servidor.

A autenticação é feita via QR Code: basta escanear com o celular que terá o número ativo, exatamente como quando você acessa o WhatsApp Web normalmente.

📱 Como conectar o número

1. Clique em ▶ Iniciar Serviço — o Chrome sobe em segundo plano.
2. Clique em 📱 QR Code para abrir o painel lateral.
3. No celular: WhatsApp → Menu (⋮) → Dispositivos conectados → Conectar dispositivo.
4. Aponte a câmera para o QR Code exibido na tela.
5. Após escanear, o status muda para Conectado e o número passa a receber currículos.

💾 Sessão persistente

Após o primeiro escaneamento do QR Code, a sessão é salva automaticamente. Nas próximas vezes que o serviço for iniciado, ele reconecta sem precisar escanear novamente — desde que o número não tenha sido desconectado pelo celular. Para trocar o número, use o botão 🔄 Trocar número no painel QR.

⚠️ Importante: O whatsapp-web.js é uma solução não oficial da Meta. O WhatsApp pode limitar ou bloquear números que enviam/recebem mensagens automatizadas em alto volume. Para uso comercial intenso, use a API Oficial do WhatsApp Business (Meta) — configurável em Configuração → API Oficial Meta.
🟢 API Oficial Meta (alternativa paga)

Quando ativada em Configuração, o sistema usa a Cloud API da Meta em vez do whatsapp-web.js. Neste modo:

• Sem QR Code — a autenticação é via token permanente gerado no Meta Developer Console.
• Sem risco de bloqueio — é a API oficial, suportada pela Meta.
• Webhook — a Meta envia mensagens para a URL /api/whatsapp/webhook/meta do seu servidor. O servidor precisa ter um endereço público (HTTPS) acessível pela Meta.
• Custo — a Meta cobra por conversa iniciada (modelo de pricing em conversas de 24h). Verifique os preços em developers.facebook.com/docs/whatsapp/pricing.

🔄 Estratégia: Groq como primário, Gemini como fallback

O sistema tenta 3 vezes antes de desistir, sempre na ordem abaixo:

⚡ 1ª e 2ª tentativas — Groq (Llama 3.3 70B / Llama 3.1 8B)

Motor principal. Cada currículo é enviado ao modelo Llama 3.3 70B Versatile via API Groq. Se falhar, uma segunda tentativa usa o modelo mais rápido Llama 3.1 8B Instant.

A Groq oferece um plano gratuito generoso com limite de tokens por dia — suficiente para uso moderado sem custo algum.

🔗 console.groq.com — Criar conta / gerenciar créditos
🌐 3ª tentativa — Google Gemini (fallback automático)

Ativado automaticamente quando a Groq retorna erro de limite (429) ou quota excedida. O sistema reanalisa o currículo com Gemini sem nenhuma intervenção do operador.

O modelo usado é configurável em Configurações → Chaves de API → Modelo Gemini (padrão: gemini-1.5-flash).

🛡️ Proteção contra falhas

Se todas as 3 tentativas falharem, o currículo ainda é salvo no banco com os dados brutos extraídos do PDF, sem ser descartado. Nenhum candidato é perdido por problemas técnicos de IA.

As chaves de API são configuradas em Configurações → Chaves de API e são armazenadas por empresa (cada empresa pode ter suas próprias chaves).
