🟢 API Oficial WhatsApp Business (Meta)
Quando usar? Para uso comercial em volume, estabilidade garantida pela Meta e sem risco de bloqueio de número. Requer uma conta no Meta Business com WhatsApp Business API habilitada.
Quando ativado, o sistema usa a Cloud API da Meta em vez do whatsapp-web.js.
Gere em Meta Developer Console → WhatsApp → API Setup → Permanent Token.
Encontrado em Meta Developer Console → WhatsApp → API Setup → Phone Number ID.
Você define este token livremente e usa o mesmo no Meta Developer Console ao configurar o webhook.
Configure esta URL em Meta Developer Console → WhatsApp → Configuration → Webhook. Campo Callback URL.
ℹ Como funciona
O bot recebe currículos em PDF enviados para o número conectado via QR Code no Monitor.
Após analisar com IA, as informações são enviadas para o Número de Destino acima.
Para conectar o WhatsApp, acesse Monitor → Iniciar Serviço.
