Integração de Currículos ao SE
Define como os currículos analisados são enviados ao Softexpert.
Escolha entre integração padrão (SOAP legada) ou via SE API Configurador (Flow).
Integração Padrão (legada)
SOAP fixo via token SE — configuração original
SE API Configurador — Flow
Executa um Flow configurável com sequência de APIs por candidato
SE API Configurador — Grid (Lote)
Envia todos os aprovados em uma única chamada newChildEntityRecordList
Configure flows no SE API Configurador. Cada Config deve ter Tabela de Origem: currículos.
Configure um Flow no SE API Configurador com:
• Step 1: Config tipo GRID — template com {{workflow_id}} e {{grid_rows}}
• Step 2 (opcional): Config tipo MOVE — para avançar atividade após inserir os candidatos
O {{workflow_id}} é preenchido automaticamente com o WorkflowID da vaga integrada.
Integração de Funções ao SE
Define o Flow do SE API Configurador usado para enviar cadastros de funções ao Softexpert.
A integração pode ser disparada individualmente ou em lote a partir do Cadastro de Funções.
⚡ —
Configure flows no SE API Configurador. Cada Config deve ter Tabela de Origem: funções.
