Groq ⚡ Rápido
Alta velocidade, ideal para respostas rápidas em tempo real.
Obtida em console.groq.com → API Keys. Deixe em branco para manter a chave atual.
Modelo usado quando Groq for acionado (principal ou fallback).
✦
OpenAI ✦ GPT-4o
Modelos GPT da OpenAI. Usa gpt-4o-mini por padrão — alto desempenho e custo acessível.
Obtida em platform.openai.com → API Keys. Deixe em branco para manter a chave atual.
Modelo usado quando OpenAI for acionado (principal ou fallback).
◆
Claude (Anthropic) ◆ Elite
Fallback com suporte a análise de imagem (anexos).
Obtida em console.anthropic.com → API Keys. Deixe em branco para manter a chave atual.
Modelo usado quando Claude for acionado (principal ou fallback).
✦
Gemini ✦ Multimodal
Fallback com suporte a análise de imagem (anexos).
Obtida em aistudio.google.com → Get API Key. Deixe em branco para manter a chave atual.
Modelo usado quando Gemini for acionado (principal ou fallback).
Ordem de uso
Qual provedor tentar primeiro, e a ordem de fallback se ele falhar ou estiver sem chave.
O provedor primário é tentado primeiro; depois entra a ordem de fallback abaixo.
⭐ Recomendado
Econômico & Rápido
Groq→ OpenAI→ Claude→ Gemini
Groq como principal (rápido, custo baixo). Os demais entram em ordem se ele falhar ou estiver sem chave.
🏆 Alta Qualidade
Máxima Qualidade
Groq→ Claude→ OpenAI→ Gemini
Groq principal, Claude e OpenAI como fallback de alta qualidade. Ideal quando precisão é prioritária sobre custo.
