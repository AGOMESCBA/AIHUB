# IA Hub Shell

> Compatibilidade: a estrutura nova do app principal passa a ser `apps/IAHUB`.
> Esta pasta permanece por enquanto apenas como referencia da fase inicial.

Projeto principal generico da plataforma IA Hub.

Responsabilidades:
- login e sessao
- selecao de empresa
- selecao de sistema
- layout base da plataforma
- regras globais de usuario, empresa, sistemas e permissoes

Este app nao deve conter regra especifica de recrutamento.
