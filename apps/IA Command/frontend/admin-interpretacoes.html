    Ajuda - Interpretacoes
    
  

  


    

      
O que é esta tela

      
É o diário de bordo do IA Command: cada mensagem recebida via WhatsApp gera um registro aqui com a pergunta original, a decisão tomada e a resposta enviada ao cliente. Use esta tela para entender por que uma resposta saiu errada, confirmar se o sistema está aprendendo e guiar melhorias de forma segura.

    


    

      
Quando usar

      

        
Um cliente recebeu uma resposta errada ou estranha

        
Localize a mensagem pelo celular ou texto, abra o detalhe e veja exatamente o que o sistema entendeu. Verifique a intenção classificada, o dataset consultado e a resposta entregue.

      

      

        
O sistema está consumindo muitos tokens de IA externa

        
Filtre por Motor = "IA externa" e veja quais perguntas estão passando para fora. Se os termos usados ainda não têm equivalências cadastradas, adicione-as na tela de Equivalências para que o motor local resolva sem custo.

      

      

        
Validar após cadastrar uma nova equivalência ou intenção

        
Faça uma pergunta real pelo WhatsApp, volte aqui e confirme se o Motor agora aparece como "IA interna" e a Confiança está alta. É a forma mais confiável de testar sem alterar código.

      

    


    

      
Colunas principais

      

        
Pergunta / Resposta

        
O texto exato enviado pelo cliente e o que o sistema respondeu. Clique na linha para ver os dois completos.

      

      

        
Motor

        
IA interna = sistema resolveu sozinho com equivalências e intenções cadastradas — sem custo de tokens. IA externa (Groq, Gemini…) = sistema precisou de ajuda para interpretar a frase. Contexto = resposta herdada da conversa anterior.

      

      

        
Confiança

        
Percentual de certeza na classificação. Acima de 70 % é considerado bom. Valores baixos indicam que a frase estava ambígua ou faltam equivalências.

      

      

        
Intenção / Dataset

        
Qual consulta o sistema decidiu executar e em qual conjunto de dados do ERP. Se estiver errado, provavelmente falta uma equivalência ou a intenção está mal configurada.

      

      

        
Contexto

        
Indica se a resposta aproveitou informações da conversa anterior (período herdado, intenção herdada etc.). Útil para entender respostas de perguntas curtas como "e o mês passado?".

      

      

        
Fallback

        
Quando "Sim", o sistema precisou tentar um segundo provedor porque o primeiro falhou. Muitos fallbacks consecutivos indicam instabilidade em um provedor.

      

    


    

      
Detalhe e Feedback

      
Clique em qualquer linha para abrir o detalhe completo: pergunta, decisão estruturada (JSON de intenção), sinônimos aplicados, campos inferidos pela IA e resposta entregue.

      
No detalhe, registre um feedback:

      

        
Interpretação correta

        
Sistema acertou — confirma que o cadastro está bom.

      

      

        
Interpretação incorreta

        
Sistema errou. Use a observação para registrar o que deveria ter sido respondido e o que falta corrigir (equivalência, intenção ou dataset).

      

      

        
Corrigido manualmente

        
O erro já foi corrigido em outro cadastro. Marque para fechar o ciclo.

      

      

        
Ignorar para aprendizado

        
Mensagem irrelevante (teste, spam). Não serve como base para melhorias.

      

      
O feedback não altera nada no sistema automaticamente — ele cria rastreabilidade para que você saiba o que ajustar em Equivalências, Intenções ou Datasets.

    


    

      
Limpar log

      
O log cresce com o uso. Use o botão Limpar log para remover registros antigos por período ou apagar tudo da empresa. A ação é irreversível, mas fica registrada na auditoria do sistema.
