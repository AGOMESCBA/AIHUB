Ajuda — Formulário de Intenção
Identificação
Nome obrigatório
Identificador interno sem espaços. Use underscores: consultar_faturamento, consultar_titulos_abertos. Veja a aba Nomes Sugeridos para nomes com formatação rica.
Descrição
Texto que a IA usa para identificar quando o usuário quer esta informação. Seja específico: inclua exemplos de perguntas que a ativam.
Configuração
Módulo
Categoria funcional (Faturamento, Financeiro, Compras, etc.) para organizar as intenções. Cadastre módulos em Administração → Módulos.
Dataset vinculado obrigatório para ativar
Dataset cujo SQL Base será executado quando esta intenção for reconhecida. Configure o dataset antes de vincular aqui.
Frases de Exemplo
Adicione as variações de pergunta que os usuários usam. Quanto mais exemplos, mais precisa é a classificação.
A IA aprende pelo contexto dos exemplos. Inclua variações informais que o seu time usa no dia a dia.
Dados do Registro
Status
Somente intenções ativas são reconhecidas pelo motor de IA. Desative para pausar sem excluir.
