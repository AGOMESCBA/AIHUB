    Ajuda - Shadow NL-SQL
    
  

  

    

      
      
      
    


    

      

        
O que e esta tela

        
E a auditoria comparativa do Shadow Mode. Ela mostra qual consulta semantica o sistema teria escolhido e compara esse candidato com o SQL real gerado pela LLM na execucao de verdade.

      

      

        
Objetivo

        
Validar qualidade antes de colocar auto-reuse em producao. O candidato registrado aqui nao foi executado para o usuario; ele foi apenas medido contra o resultado real para formar estatistica confiavel.

      

      

        
Como usar

        
Filtre por periodo, modulo, resultado e classificacao. Comece pelos mismatches e templates invalidos; depois confira se os matches possuem amostra suficiente para justificar liberacao automatica.

      

    


    

      

        
Resultados

        
Match template exato e o melhor sinal: o candidato tinha o mesmo template do SQL real. Match SQL aplicado indica SQL final equivalente apos parametros. Mismatch mostra divergencia. Template invalido aponta candidato inutilizavel. Sem candidato indica que nada passou do limiar.

      

      

        
Exemplos praticos

        
Se Financeiro tem muitos matches com score alto, essa faixa pode virar candidata a liberacao em Decisoes Automaticas. Se Compras tem mismatches, abra o detalhe e compare Template candidato x Template real para entender qual filtro, periodo ou agrupamento confundiu o ranking.

      

    


    

      

        
Configuracao recomendada para subir

        
    
          
  • Shadow Mode ligado: grava candidatos, mede precisao e alimenta esta auditoria.
    • 
          
  • Auto-liberar por precisao ligado: quando atingir a amostra minima e a precisao configurada, o sistema marca a politica como liberado.
    • 
          
  • Auto-reuse semantico desligado: mantem producao usando IA + SQL Canonico, sem servir candidato semantico automaticamente.
    • 
        

        
Essa combinacao permite aprender em producao sem mudar o comportamento das respostas.

      

      

        
Quando quiser executar auto-reuse

        
    
          
  • Ligue Auto-reuse semantico em Aprendizado NL-SQL > Decisoes Automaticas.
    • 
          
  • A politica precisa estar persistida como liberado.
    • 
          
  • O score do candidato precisa atingir o limite de execucao.
    • 
          
  • O template precisa aplicar sem pendencias e o SQL precisa passar novamente pelos validadores.
    • 
        

      

      

        
Como desligar

        
    
          
  • Para parar apenas a execucao automatica, desligue Auto-reuse semantico. O Shadow Mode continua gravando.
    • 
          
  • Para parar tambem a coleta de aprendizado, desligue Shadow Mode.
    • 
          
  • Como emergencia tecnica, a variavel IAC_NLSQL_SEMANTIC_AUTO_REUSE=0 desliga o auto-reuse no ambiente.
    •
