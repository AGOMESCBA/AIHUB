Ajuda - Dicionário SX2
O que é esta tela
O Dicionário SX2 registra o modo de compartilhamento de cada tabela do Protheus. Antes de gerar qualquer SQL, a IA consulta esta tabela para saber qual filtro de filial aplicar — sem isso, queries podem retornar dados de filiais erradas ou cruzar registros que deveriam ser isolados.
Modos de compartilhamento
E — Exclusivo
A tabela pertence exclusivamente à filial. A IA aplica o filtro FILIAL = '01' (ou o valor configurado na conexão). Cada filial tem seus próprios registros.
C — Compartilhado
Registros compartilhados entre todas as filiais. A IA aplica o filtro FILIAL = ' ' (dois espaços). Os dados são comuns a toda a empresa.
G — Global
Tabela global, também filtrada por dois espaços. Usado em tabelas de parâmetros e configurações que não pertencem a nenhuma filial específica.
Na dúvida sobre o modo de uma tabela, consulte o próprio Protheus em Configurador › Dicionários › SX2 ou use a importação direta do banco.
Quando usar
A IA está gerando SQL com filtro de filial errado
Verifique se a tabela está cadastrada no SX2 com o modo correto. Se estiver ausente, a IA usa o modo padrão configurado na conexão, que pode não corresponder à realidade do Protheus.
Adicionei uma nova tabela ao escopo de consultas da IA
Cadastre o modo da tabela aqui antes de criar o dataset correspondente. Assim o filtro de filial já estará correto na primeira consulta gerada.
Atualização após mudança no ERP
Se o modo de uma tabela mudou no Protheus (ex.: passou de Exclusiva para Compartilhada), atualize o registro aqui para que a IA reflita a nova configuração imediatamente.
Colunas da grade
Chave (X2_CHAVE)
Identificador lógico da tabela no Protheus (ex.: SD1, SE2, SA2). É o prefixo usado nos campos dentro das queries SQL.
Arquivo (X2_ARQUIVO)
Nome real da tabela no banco de dados (ex.: SD1010, SE2990). Pode ter sufixo numérico correspondente à empresa.
Modo
E, C ou G — define o filtro de filial que a IA irá aplicar ao gerar SQL para esta tabela.
Importação
Do banco de dados
Conecta diretamente ao banco ERP pela conexão selecionada e lista as tabelas SX2 disponíveis. É a forma mais rápida e garante dados atualizados. Os registros existentes da conexão são substituídos.
De arquivo DBF
Permite carregar o arquivo SX2010.DBF exportado do Protheus diretamente do seu computador. Útil quando não há acesso direto ao banco. O arquivo é processado localmente no navegador — nenhum dado binário é enviado ao servidor.
