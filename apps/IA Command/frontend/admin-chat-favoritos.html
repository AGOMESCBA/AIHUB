Ajuda: macros e execucao
Use estas variaveis no SQL final para evitar datas fixas em favoritos recorrentes.

Ao executar um favorito no chat, o IA Command usa o SQL salvo diretamente, sem chamar IA e sem consumir token. Antes de consultar o ERP, o executor troca as macros abaixo pela data atual do servidor.

{{HOJE}} {{ONTEM}} {{AMANHA}} {{HOJE:-7}} {{INICIO_SEMANA}} {{FIM_SEMANA}} {{INICIO_SEMANA_ANTERIOR}} {{FIM_SEMANA_ANTERIOR}} {{INICIO_PROXIMA_SEMANA}} {{FIM_PROXIMA_SEMANA}} {{INICIO_MES}} {{FIM_MES}} {{INICIO_MES_ANTERIOR}} {{FIM_MES_ANTERIOR}} {{INICIO_ANO}} {{FIM_ANO}} {{INICIO_ANO_ANTERIOR}} {{FIM_ANO_ANTERIOR}}

Campos Protheus em AAAAMMDD usam as macros acima. Para campos em YYYY-MM-DD, use a versao _ISO, como {{ONTEM_ISO}}.

SET ROWCOUNT 10000;
SELECT *
FROM SE2010 SE2
WHERE SE2.D_E_L_E_T_ = ' '
  AND SE2.E2_VENCREA = '{{ONTEM}}';

Novos favoritos criados pelo chat tentam gravar macro automaticamente quando a pergunta tem periodo relativo claro, como hoje, ontem, semana atual, semana passada, proxima semana, mes atual ou mes anterior. Favoritos antigos podem ser ajustados manualmente aqui.
