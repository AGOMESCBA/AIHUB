Ajuda - Dicionário SX3
O que é esta tela
O Dicionário SX3 descreve os campos de cada tabela do Protheus — nome, tipo, tamanho, título e descrição. Antes de gerar um SQL, a IA consulta este dicionário para validar se um campo existe na tabela, evitar nomes incorretos e inferir o tipo de dado esperado. Quanto mais completo o SX3, mais precisa a geração de SQL.
Quando usar
A IA está usando campos que não existem na tabela
Verifique se a tabela está importada no SX3 para a conexão correta. Se não estiver, a IA tentará inferir os campos pelo nome, o que pode gerar erros de SQL em produção.
Adicionei uma nova tabela ao escopo de consultas da IA
Importe os campos da tabela aqui antes de criar o dataset correspondente. Assim a IA já conhece os campos disponíveis e seus tipos ao gerar o primeiro SQL.
O Protheus recebeu uma atualização ou customização
Se novos campos foram adicionados ou renomeados no ERP, reimporte a tabela afetada para que a IA use os nomes corretos.
Colunas da grade
Tabela (X3_ARQUIVO)
Nome da tabela no Protheus à qual o campo pertence (ex.: SE1, SA2, SD1). Use o filtro de tabela na barra de pesquisa para isolar rapidamente todos os campos de uma tabela específica.
Campo (X3_CAMPO)
Nome exato do campo no banco de dados (ex.: E1_NUM, A2_COD). É o valor que a IA usa ao montar o SQL.
Tipo
C = Caractere, N = Numérico, D = Data, L = Lógico, M = Memo. A IA usa o tipo para formatar corretamente os literais nas cláusulas WHERE e SELECT.
Tamanho / Decimal
Tamanho total e casas decimais do campo. Auxiliam a IA a validar se um valor informado pelo usuário cabe no campo antes de incluí-lo na query.
Título / Descrição
Rótulos amigáveis vindos do dicionário Protheus. A IA usa esses textos para associar termos do usuário (ex.: "número do título") ao campo correto (E1_NUM) sem depender de equivalências manuais.
Importação
Do banco de dados
Conecta ao banco ERP e lista as tabelas SX3 disponíveis. Selecione a tabela desejada e importe — os campos anteriores desta conexão são substituídos pelos campos atuais do banco. É a forma mais rápida e confiável.
De arquivo DBF
Permite carregar o arquivo SX3010.DBF exportado do Protheus. Útil em ambientes sem acesso direto ao banco. O arquivo é lido no navegador — somente os registros processados são enviados ao servidor.
Para ambientes com muitas tabelas, use a importação por tabela específica em vez de reimportar tudo — é mais rápido e evita substituir campos de outras tabelas que estão corretos.
