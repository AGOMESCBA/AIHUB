O que é a Normalização Linguística
A Normalização é a primeira camada de processamento do IA Command. Antes de qualquer interpretação de intenção, período, filtro ou chamada à IA, o motor substitui termos digitados pelo usuário por suas formas corretas — corrigindo erros de digitação, expandindo abreviações e padronizando variações de escrita.
Exemplo: o usuário envia "conparar faturamnto desse mes". A normalização transforma para "comparar faturamento desse mes" antes de qualquer análise.
Posição no pipeline
A normalização ocorre nesta ordem dentro do IA Command:
1. Normalização Linguística ← você está aqui
2. Intenção (qual consulta o usuário quer)
3. Período (quando)
4. Filtros e agrupamentos
5. Execução no dataset / chamada à IA
Uma regra de normalização bem configurada aumenta o índice de resolução local e reduz chamadas à IA externa, economizando tokens.
Campos do cadastro
Termo digitado
O texto exato que o usuário pode escrever no WhatsApp — com erro, abreviação ou variação. Não precisa ser uma palavra inteira; funciona como busca de substring na mensagem.
Forma normalizada
O texto correto que o motor deve usar no lugar do termo digitado antes de interpretar o pedido.
Tipo
Classifica a regra para facilitar organização e filtragem. Não altera o comportamento — ver aba Tipos.
Status
Apenas regras Ativas são aplicadas pelo motor. Inative uma regra para suspendê-la sem excluir.
Tipos disponíveis
O tipo é apenas uma categoria organizacional — não muda como a regra é aplicada. Use-o para filtrar e entender a origem dos cadastros.

Regras embutidas no sistema
O IA Command já vem com variantes pré-definidas no motor (não aparecem nesta lista, pois estão no código): conjugações dos verbos comparar, mostrar, trazer, listar, além de variações ortográficas de palavras frequentes como faturamento, vendas, pedidos. As regras cadastradas aqui são aplicadas adicionalmente — priorize termos específicos do vocabulário da empresa que não estão cobertos pelo motor padrão.
Não recadastre termos já cobertos pelo motor. Se a normalização já está funcionando para uma palavra, cadastrar novamente não causa dano, mas é redundante.

Boas práticas de cadastro
Termos curtos, sem espaços desnecessários
A normalização faz correspondência de substring. Prefira termos curtos como qtde em vez de qtde total para evitar falsos positivos.
Sempre teste após cadastrar
Envie a mensagem com o erro pelo WhatsApp e observe se a resposta melhora. O painel Monitor mostra a mensagem recebida e o que o motor interpretou.
Alimente a partir das reclamações reais
Quando um usuário reclamar que "não entendeu", verifique no Monitor qual foi a mensagem recebida. Se havia um erro de digitação não coberto, cadastre a regra aqui.
Inative regras que causarem substituições indesejadas em vez de excluir — assim você mantém o histórico e pode reativar se necessário.
