Módulos Permitidos
Defina quais módulos do IA Command este número pode consultar. Módulos desativados retornarão uma mensagem amigável solicitando que o usuário peça acesso ao gestor.
As permissoes por modulo sao geridas exclusivamente na aba Empresas. Esta aba mostra apenas o estado salvo para a empresa atual.
Financeiro
Consultas de contas a pagar, receber, fluxo de caixa e saldos.
Compras
Consultas de pedidos de compra, fornecedores e estoques.
Faturamento
Consultas de pedidos de venda, notas fiscais e clientes.
Comissão
Consultas de comissões de vendedores. Requer configuração de perfil ERP na aba Gestão de Vendas.
Quando um módulo está desativado, o usuário recebe a mensagem: "Ainda não consigo consultar o módulo [X] para o seu número. Peça ao gestor do IA Command para liberar esse módulo no seu cadastro de WhatsApp e tente novamente."

Ajuda - Numeros WhatsApp
Como funciona
Cadastre aqui os numeros que podem conversar com o IA Command nesta empresa. Quando existir ao menos um numero ativo, mensagens de numeros nao cadastrados serao ignoradas.
Aba: Geral
Nome
Identificacao interna do contato autorizado.
Numero
Use DDI e DDD, por exemplo 5592999999999. A comparacao usa apenas digitos.

Numeros inativos ficam registrados, mas nao autorizam novas interacoes.
Aba: Autorizações
Controle quais módulos do IA Command este número pode acessar. Se um módulo estiver desativado, o usuário receberá uma mensagem amigável orientando a solicitar acesso ao gestor.
Aba: Gestão de Vendas
Vendedor
Vê apenas as próprias comissões. O sistema aplica automaticamente o filtro pelo Código ERP informado.
Gestor
Acesso irrestrito às comissões de todos os vendedores da empresa.
Se nenhum numero ativo estiver cadastrado, o comportamento atual e mantido para evitar bloqueio acidental do atendimento.
