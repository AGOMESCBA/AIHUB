Como configurar o Protheus REST
Instale o endpoint AdvPL abaixo no seu ambiente Protheus para ativar a integração remota.
Passos:
1. Copie o código AdvPL abaixo e salve como IACommandAgent.prw no seu projeto Protheus.
2. Compile o fonte no Protheus IDE / TDS.
3. No rest.xml do seu ambiente, certifique-se de que o path /rest está habilitado.
4. Defina a API Key no próprio fonte (constante IAC_API_KEY) e recompile.
5. Use a mesma chave no campo "API Key" desta tela.

Ajuda — Conexão ERP
Modos de Conexão
SQL Server / PostgreSQL / SQLite — Conexão Direta
O IA Command acessa o banco de dados do ERP diretamente via TCP. Requer que o servidor do IA Command esteja na mesma rede que o banco (ou que a porta esteja acessível via VPN/firewall).
API REST — Conexão Remota
O IA Command envia o SELECT via HTTP para um endpoint instalado no servidor Protheus. O Protheus executa a query no banco e retorna os dados em JSON. Ideal quando o banco não está acessível diretamente pela internet.
Campos — Conexão Direta
Sistema ERP
Identifica qual ERP está sendo conectado (Protheus, Sankhya, SAP…). Não afeta a conexão em si — as tabelas e joins são definidos no SQL Base de cada dataset.
Tipo de Conexão / Driver
Define qual biblioteca de banco usar. Use SQL Server para Protheus e a maioria dos ERPs brasileiros. PostgreSQL para instalações Linux/nuvem. SQLite apenas para testes locais.
Servidor (host) e Porta
Endereço IP ou hostname do servidor de banco de dados. Porta padrão SQL Server: 1433. Se o SQL Server usar uma instância nomeada (ex: SERVIDOR\SQLEXPRESS), informe o hostname com o nome da instância.
Database
Nome do banco de dados dentro do SQL Server. No Protheus costuma ser PROTHEUS12, PROTHEUS11 ou similar, dependendo da versão.
Usuário e Senha
Credenciais de acesso ao banco. Crie um usuário dedicado com permissão somente leitura (SELECT) nas tabelas do ERP. Nunca use sa em produção.
Encrypt
Força criptografia TLS entre o IA Command e o SQL Server. Nas versões mais novas do driver (mssql v10+) já vem ativado por padrão. Mantenha ativo em ambientes de nuvem ou redes públicas. Em redes internas corporativas pode ser desativado se o SQL Server não suportar TLS.
Trust Cert (Trust Server Certificate)
Quando a criptografia está ativa, esta opção diz ao IA Command para aceitar o certificado SSL do servidor sem validar com uma Autoridade Certificadora (CA). Deve ficar marcado na grande maioria das instalações Protheus on-premise, que usam certificados auto-assinados. Se desmarcar e o certificado não for válido, a conexão falha com erro de certificado.
Regra prática: Protheus on-premise → marque Trust Cert. SQL Server em nuvem com certificado válido (Azure, AWS RDS) → pode desmarcar para maior segurança.
Campos — API REST (Protheus)
URL Base do Servidor REST
Endereço completo do servidor REST do Protheus, incluindo protocolo e porta. Exemplo: https://protheus.empresa.com.br:8080. É o mesmo endereço usado para acessar os serviços REST do Protheus pelo navegador.
Caminho do Endpoint
Prefixo das rotas do agente IA Command instaladas no Protheus. Padrão: /rest/api/iacommand/v1. O IA Command chamará /execute e /ping neste caminho. Altere apenas se você modificou o fonte AdvPL.
API Key / Bearer Token
Chave secreta definida na constante IAC_API_KEY do fonte AdvPL instalado no Protheus. O IA Command envia esta chave no header Authorization: Bearer <key> em cada chamada. Use uma string longa e aleatória.
Testando a Conexão
O que o teste faz?
— Modo direto: abre uma conexão TCP com o banco e executa SELECT 1.
— Modo API REST: chama GET /ping no agente Protheus e verifica a resposta.
Salve a conexão antes de testar.
Ativar como padrão
Após testar com sucesso, acesse a lista de conexões e clique em "Ativar" para definir esta conexão como a padrão da empresa. Somente a conexão ativa é usada pelo bot.
Boas Práticas de Segurança
Usuário somente leitura
Crie um login SQL com permissão apenas de SELECT nas tabelas que serão consultadas. O IA Command nunca precisa de INSERT, UPDATE ou DELETE.
Restringir acesso por IP
No firewall do servidor, libere a porta do banco (1433) ou do REST somente para o IP do servidor do IA Command. Evite abrir para 0.0.0.0/0.
Modo API REST — troque a chave periodicamente
A IAC_API_KEY é a única barreira de acesso ao endpoint AdvPL. Troque-a periodicamente, recompile o fonte e atualize aqui. Considere usar HTTPS com certificado válido no servidor REST.
