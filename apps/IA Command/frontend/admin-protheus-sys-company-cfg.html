Ajuda — Dicionário SYS_COMPANY_CFG
O que é esta tela
O Dicionário SYS_COMPANY_CFG guarda a hierarquia completa (Grupo / Empresa / Unidade / Filial) via um campo de tipo de nó (ex.: XX8_TIPO). É o que permite distinguir formalmente duas empresas jurídicas diferentes dentro do mesmo grupo Protheus — o Dicionário SYS_COMPANY sozinho só descreve filiais, sem esse nível de detalhe.
Perfil de campos — por que confirmar antes de importar
Nomes de campo (XX8_EMPR, XX8_TIPO etc.) e os valores de tipo de nó por nível variam por instalação e versão do Protheus. Antes de importar, use ⚙ Perfil de campos e confirme contra o schema real da conexão (INFORMATION_SCHEMA.COLUMNS) — nunca presuma que os nomes padrão estão corretos.
Exemplo validado numa instalação real: XX8_TIPO 0=Grupo, 1=Empresa, 2=Unidade, 3=Filial. Isso não é garantido em outra instalação.
Validação — falha fechado
A validação confere se todo código de filial gravado numa tabela de negócio real existe na hierarquia importada, e se não há chave duplicada dentro do grupo. Só libera uso automático quando a checagem é 100% limpa. Qualquer divergência mantém o grupo em modo assistido — isolamento parcial de dados entre empresas é pior que bloqueio.
