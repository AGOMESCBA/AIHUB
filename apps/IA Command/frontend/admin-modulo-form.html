Ajuda — Formulário de Módulo
Identificação
Nome obrigatório
Nome do módulo como aparece nos filtros da lista de intenções e no formulário de intenção. Use nomes funcionais simples: Faturamento, Financeiro, Estoque, RH.
Descrição
Texto informativo para a equipe de configuração. Não aparece para o usuário final.
Aparência
Cor do badge
Cor exibida no badge do módulo na lista de intenções. Clique na bolinha colorida ou digite um código hex (#7c3aed). Cada módulo pode ter uma cor diferente para facilitar a distinção visual.
Dados do Registro
Status
Módulos inativos não aparecem no seletor de módulo dentro do formulário de intenção. Use para desativar módulos que não estão mais em uso sem excluí-los.
Cadastre os módulos antes de configurar as intenções. Assim o campo Módulo no formulário de intenção já estará populado com as opções corretas.
