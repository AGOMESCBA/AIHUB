    Ajuda — Log de Execuções
    
  

  

    

      
O que aparece aqui

      
Cada linha representa uma consulta processada pelo motor de IA — seja via WhatsApp, seja via o chat interno. Clique em qualquer linha ou no ícone de olho para abrir o detalhe completo.

    

    

      
Colunas

      
Data/Hora
Momento em que a consulta foi processada.

      
Usuário / Remetente
Número do WhatsApp ou usuário do chat interno que fez a pergunta.

      
Intenção
Intenção identificada pela IA para a mensagem recebida.

      
Status
✓ Sucesso — consulta executada. ✗ Erro — falha (ver detalhe). — Sem dados — consulta executou mas retornou zero linhas.

      
Duração
Tempo total em milissegundos (IA + banco). Verde < 1s, amarelo 1-3s, vermelho > 3s.

    

    

      
Abas do detalhe

      
Dados gerais
Resumo dos metadados da execução: remetente, intenção, status, módulo, linhas retornadas e informações sobre o SQL canônico utilizado.

      
SQL / Auditoria
Exibe lado a lado o SQL final executado e a auditoria completa em JSON. Use o botão Copiar para transportar o SQL para outro ambiente. Arraste a divisória para redimensionar.

      
Detalhes técnicos
JSON bruto do campo detalhes_json — útil para diagnóstico avançado e debugging de reuso canônico.

      
Se muitas consultas retornam "intenção desconhecida", adicione mais exemplos de frases nas intenções relevantes.
