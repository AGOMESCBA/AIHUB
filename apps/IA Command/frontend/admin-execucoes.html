    Ajuda — Auditoria de Consultas IA
    
  

  

    

      
O que aparece aqui

      
Cada linha representa uma consulta de IA auditável: pergunta original, intenção, Intent Canônico, status do cache, SQL final executado e template parametrizado.

    

    

      
Objetivo

      
Investigar uma execução específica e entender exatamente o que aconteceu: o que o usuário perguntou, qual caminho a IA escolheu, qual SQL foi executado, se houve cache e quanto tempo levou.

    

    

      
Colunas

      
Data/Hora
Momento em que a consulta foi processada.

      
Usuário / Remetente
Número do WhatsApp ou usuário do chat interno que fez a pergunta.

      
Pergunta / Intenção
Texto recebido e intenção identificada para a consulta.

      
Cache
Mostra se a execução está pendente, confiável, inapta ou bloqueada por feedback para reaproveitamento determinístico.

      
Template
Indica se existe SQL parametrizado salvo para reuso com novos períodos e filtros resolvidos.

      
Status
✓ Sucesso — consulta executada. ✗ Erro — falha (ver detalhe). — Sem dados — consulta executou mas retornou zero linhas.

      
Duração
Tempo total em milissegundos (IA + banco). Verde < 1s, amarelo 1-3s, vermelho > 3s.

    

    

      
Abas do detalhe

      
Dados gerais
Resumo operacional: pergunta, remetente, intenção, status, módulo, linhas retornadas e chave de cache.

      
Intent / Cache
Mostra o Intent Canônico persistido e o contrato estrutural usado para cache, versionamento e quarentena.

      
SQL / Template
Exibe lado a lado o SQL final executado e o template parametrizado usado no reuso determinístico.

      
JSON bruto
Mostra execution_log, detalhes_json e auditoria SQL completa para diagnóstico avançado.

    

    

      
Exemplos práticos

      
Resposta errada
Busque pelo texto da pergunta, abra o detalhe e compare intenção, SQL final e resposta entregue.

      
Cache suspeito
Filtre por cache confiável ou bloqueado, abra o registro e confira a chave de cache e o template usado.

      
Lentidão
Ordene por processamento ou entrega para encontrar consultas lentas e verificar se o problema veio da IA, do banco ou do volume retornado.

      
Se muitas consultas retornam "intenção desconhecida", adicione mais exemplos de frases nas intenções relevantes.
