O que aparece aqui

      
Cada linha representa uma consulta processada pelo motor de IA — seja via WhatsApp, seja via o chat interno. Somente leitura. Os dados não podem ser editados ou excluídos por aqui.

    

    

      
Colunas

      
Data/Hora
Momento em que a consulta foi processada.

      
Usuário / Remetente
Número do WhatsApp ou usuário do chat interno que fez a pergunta.

      
Intenção
Intenção identificada pela IA para a mensagem recebida.

      
Status
✓ Sucesso — consulta executada e resposta enviada. ✗ Erro — falha na execução (ver detalhe).

      
Tempo
Tempo total de processamento em milissegundos (IA + banco de dados).

    

    

      
Diagnosticando erros

      
Clique em qualquer linha para abrir o detalhe completo: pergunta original, SQL executado, resposta da IA e mensagem de erro (se houver). Use isso para identificar problemas no SQL Base ou na classificação de intenções.

      
Se muitas consultas retornam "intenção desconhecida", adicione mais exemplos de frases nas intenções relevantes.
