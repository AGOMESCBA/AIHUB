    Ajuda - Interpretacoes
    
  

  

    
O que e esta tela

    
E o diario de bordo do IA Command: cada mensagem recebida via WhatsApp gera um registro aqui com a pergunta original, a decisao tomada e a resposta enviada ao cliente. Use esta tela para entender por que uma resposta saiu errada, confirmar se o sistema esta aprendendo e guiar melhorias de forma segura.

    
Coluna Pipeline

    
Chat-first: a pergunta foi enviada ao modelo de IA no formato de conversa. Classico: usou o pipeline legado. Reuso: SQL canonico reutilizado sem nova chamada a IA. Consolidado: resposta montada a partir do pipeline dinamico consolidado.

    
Abas do detalhe

    
Dados gerais: metadados, motor, pipeline, duracao, confianca, intencao e pergunta original. Query: SQL gerado/executado e resposta completa entregue ao usuario. Prompt IA: prompts registrados para auditoria. Dialogo: trace do caminho percorrido e decisao estruturada em JSON.

    
Quando usar

    
Localize uma mensagem pelo celular ou texto, abra o detalhe e veja exatamente o que o sistema entendeu. Para validar equivalencias ou intencoes novas, faca uma pergunta real pelo WhatsApp e confira aqui se o motor, a intencao e o dataset foram escolhidos corretamente.

    
Limpar log

    
Use o botao Limpar log para remover registros antigos por periodo ou apagar tudo da empresa. A acao e irreversivel, mas fica registrada na auditoria do sistema.
