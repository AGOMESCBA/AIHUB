Ajuda - Perguntas Agendadas
Como o job executa
Cada job pertence a uma empresa, usa um canal WhatsApp vinculado e envia a resposta apenas para numeros autorizados daquela empresa. Quando houver varios destinatarios, a consulta e executada uma unica vez e a mesma resposta e entregue para todos.
SQL fixo opcional
Campo vazio
O IA Command interpreta a pergunta e gera o SQL dinamicamente, como acontece nas mensagens normais.
Campo preenchido
O sistema pula a etapa de geracao por IA, executa o SQL informado, formata o resultado e envia a resposta. O modulo esperado deve ser informado para escolher a conexao correta.
Modulos Protheus (Compras, Financeiro, Faturamento, Comissao)
Usam handler dedicado, com as mesmas regras de seguranca e autorizacao por numero das perguntas em linguagem natural.
Outros sistemas (ex: SoftExpert)
O SQL roda diretamente na conexao do sistema, sem handler especializado nem autorizacao granular por numero. Escreva o SQL com cuidado, como um administrador de confianca.
Use SQL fixo para relatorios estaveis e recorrentes. Evite datas literais, como 20260731, porque elas deixam o job preso em um periodo antigo.
Macros de data
As macros sao substituidas no momento da execucao, usando o timezone configurado no job.
Formato Protheus
Retorna data como texto YYYYMMDD, usado em campos Protheus como F2_EMISSAO.
{{HOJE}} 20260731 {{ONTEM}} 20260730 {{AMANHA}} 20260801 {{INICIO_MES}} 20260701 {{FIM_MES}} 20260731 {{INICIO_MES_ANTERIOR}} 20260601 {{FIM_MES_ANTERIOR}} 20260630 {{INICIO_ANO}} 20260101 {{FIM_ANO}} 20261231 {{INICIO_ANO_ANTERIOR}} 20250101 {{FIM_ANO_ANTERIOR}} 20251231
Formato ISO
Retorna data como YYYY-MM-DD, formato padrao para campos DATE/DATETIME no SQL Server e em bancos relacionais. Use quando o campo da tabela for uma data real, ou quando fizer CAST(... AS DATE).
{{HOJE_ISO}} 2026-07-31 {{ONTEM_ISO}} 2026-07-30 {{AMANHA_ISO}} 2026-08-01 {{INICIO_MES_ISO}} 2026-07-01 {{FIM_MES_ISO}} 2026-07-31 {{INICIO_MES_ANTERIOR_ISO}} 2026-06-01 {{FIM_MES_ANTERIOR_ISO}} 2026-06-30 {{INICIO_ANO_ISO}} 2026-01-01 {{FIM_ANO_ISO}} 2026-12-31 {{INICIO_ANO_ANTERIOR_ISO}} 2025-01-01 {{FIM_ANO_ANTERIOR_ISO}} 2025-12-31
Tambem existem macros separadas para partes da data: {{ANO}}, {{MES}} e {{DIA}}.
Deslocamentos
Use dois pontos e um numero para voltar ou avancar periodos. Em macros de mes, o numero representa meses. Em macros de ano, representa anos. Em {{HOJE}}, representa dias.
{{INICIO_MES:-1}} inicio do mes anterior em Protheus {{INICIO_MES_ISO:-1}} inicio do mes anterior em ISO {{FIM_MES:-12}} fim do mesmo mes do ano passado em Protheus {{FIM_MES_ISO:-12}} fim do mesmo mes do ano passado em ISO {{INICIO_ANO:-1}} inicio do ano passado em Protheus {{INICIO_ANO_ISO:-1}} inicio do ano passado em ISO {{FIM_ANO:-2}} fim do ano retrasado em Protheus {{FIM_ANO_ISO:-2}} fim do ano retrasado em ISO {{HOJE:-7}} data de 7 dias atras em Protheus {{HOJE_ISO:-7}} data de 7 dias atras em ISO
Exemplos
Consulta do dia
WHERE SF2.F2_EMISSAO = '{{HOJE}}'
Consulta do mes atual
WHERE SF2.F2_EMISSAO BETWEEN '{{INICIO_MES}}' AND '{{FIM_MES}}'
Campo DATE/DATETIME no SQL Server
WHERE CAST(DATA_EMISSAO AS DATE) BETWEEN '{{INICIO_MES_ISO}}' AND '{{FIM_MES_ISO}}'
Mes anterior
WHERE SF2.F2_EMISSAO BETWEEN '{{INICIO_MES:-1}}' AND '{{FIM_MES:-1}}'
Ano passado
WHERE SF2.F2_EMISSAO BETWEEN '{{INICIO_ANO:-1}}' AND '{{FIM_ANO:-1}}'
Ano passado em campo DATE/DATETIME
WHERE DATA_EMISSAO >= '{{INICIO_ANO_ISO:-1}}' AND DATA_EMISSAO < DATEADD(DAY, 1, '{{FIM_ANO_ISO:-1}}')
Ano retrasado
WHERE SF2.F2_EMISSAO BETWEEN '{{INICIO_ANO:-2}}' AND '{{FIM_ANO:-2}}'
Mesmo mes do ano passado
WHERE SF2.F2_EMISSAO BETWEEN '{{INICIO_MES:-12}}' AND '{{FIM_MES:-12}}'
Limite de linhas
SET ROWCOUNT 10000; WITH dados AS (...) SELECT * FROM dados;
Cuidados
O SQL fixo deve ser uma consulta de leitura, iniciando com SELECT ou WITH. O prefixo SET ROWCOUNT numerico e aceito antes da consulta. Comandos de escrita, alteracao de estrutura ou execucao dinamica sao bloqueados.
