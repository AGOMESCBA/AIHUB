    Ajuda — Monitor WhatsApp
    
  

  

    

      
O que é esta tela

      
O Monitor WhatsApp controla a conexão do bot com o número de WhatsApp da empresa. É aqui que você inicia, para e acompanha o status do serviço em tempo real.

    

    

      
Botões da toolbar

      

        
▶ Iniciar

        
Inicia o serviço WhatsApp. O sistema gerará um QR Code no painel lateral para você escanear com o celular.

      

      

        
■ Parar

        
Encerra a sessão WhatsApp. O número ficará desconectado e não receberá mais mensagens até o próximo início.

      

      

        
📤 Teste de envio

        
Disponível apenas quando conectado. Envia uma mensagem de teste para qualquer número, útil para validar a conexão.

      

      

        
🗑 Limpar logs

        
Apaga o terminal de log visualmente (não apaga histórico do servidor).

      

    

    

      
Painel QR Code

      
Ao iniciar, um QR Code aparece no painel direito. Escaneie com o WhatsApp do celular em Configurações → Aparelhos conectados → Conectar aparelho. O QR expira em ~60 segundos — se expirar, clique em Iniciar novamente.

      
Use um número dedicado ao bot. Enquanto conectado, o número não pode ser usado normalmente no celular.

    

    

      
Painel Última Consulta

      
Exibido após cada consulta ao ERP. Campos-chave para diagnóstico:

      

        
🔵 Chat-first / ⚙️ Clássico / ♻️ Reuso canônico

        
Badge de pipeline — indica qual caminho processou a mensagem. Chat-first é o novo fluxo conversacional. Clássico indica que o chat falhou e o pipeline de 3 fases assumiu. Reuso canônico significa que o SQL já foi gerado por outra empresa no mesmo envio.

      

      

        
Turno chat

        
Número da pergunta na conversa atual (1 = primeira mensagem, 3 = terceira, etc.). Útil para depurar falhas de herança de contexto.

      

      

        
SQL gerado ▼ ver

        
O SQL produzido pela IA (canônico, sem sufixo de empresa). Clique em "ver" para expandir. Compare com o SQL executado no histórico de interpretações para identificar transformações da camada SX2.

      

      

        
Validação (aviso amarelo)

        
Aparece quando o chat-service gerou SQL inválido e o sistema caiu para o pipeline clássico. Indica o motivo da rejeição (ex: CONSULTA_NAO_COMPREENDIDA, operação não permitida).

      

      
Para ver o histórico completo com todos os campos (SQL canônico, SQL executado, duração, trace), abra a tela de Interpretações no menu.

    

    

      
Cores do log em tempo real

      
Roxo — Mensagem recebida
Uma mensagem chegou de um usuário. Mostra o remetente e o conteúdo (primeiros 60 caracteres).

      
Verde — Sucesso
Operação concluída com êxito (consulta processada, resposta enviada, etc.).

      
Vermelho — Erro
Falha no processamento. Verifique se a conexão ERP está ativa e o Dataset configurado.

      
Amarelo — Aviso
Situação que merece atenção mas não impediu o funcionamento (ex: intenção não reconhecida).
