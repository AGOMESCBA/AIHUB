O que são os templates
Os templates são os textos que o IA Command envia automaticamente pelo WhatsApp em resposta a eventos específicos — boas-vindas, erros, seleção de empresa, resultado de consulta, etc. Cada template tem uma chave única que identifica em qual situação ele é usado.
Os templates não controlam a lógica — apenas o texto. A situação em que cada um é disparado é fixada no código do sistema.
Padrão vs. Customizado
Padrão
Texto original definido pelo sistema. Sempre disponível como referência no campo Padrão do Sistema ao editar.
Customizado
Indica que o texto foi editado pela empresa. O motor usa este texto no lugar do padrão. A coluna Tipo na lista exibe o badge Customizado para facilitar identificação.
Campos do formulário
Chave
Identificador técnico do template. Não pode ser alterado — é o código que o sistema usa para encontrar a mensagem certa.
Título
Nome descritivo para facilitar identificação na lista. Pode ser editado livremente.
Template
Texto que será enviado no WhatsApp. Suporta variáveis entre chaves duplas, quebras de linha e formatação simples.
Status
Quando Inativo, o template é ignorado e o sistema usa o texto padrão embutido.
Como usar variáveis
Variáveis são substituídas em tempo real pelos valores reais do contexto da mensagem. Escreva entre chaves duplas: {{nome_da_variavel}}. Na tela de edição, clique nos chips abaixo do textarea para inserir no cursor.
Variáveis disponíveis
VariávelO que substitui
{{empresa_nome}}Nome da empresa da sessão ativa do usuário
{{empresa_id}}ID interno da empresa ativa
{{canal_nome}}Nome do canal WhatsApp que recebeu a mensagem
{{numero}}Número de telefone do remetente (formato internacional)
{{opcoes_empresas}}Lista numerada de empresas disponíveis para seleção
{{erro}}Descrição técnica do erro ocorrido
{{transcricao}}Texto transcrito de um áudio enviado pelo usuário
{{resposta}}Resposta gerada pelo motor de IA para a consulta
Nem toda variável está disponível em todos os templates — depende do contexto do evento. Se uma variável não tiver valor, ela é substituída por vazio. Verifique o Padrão do Sistema para saber quais variáveis o template original usa.

Quando customizar
Adaptar ao tom da empresa
O padrão usa uma linguagem neutra e técnica. Se a empresa preferir um tom mais informal, comercial ou com a identidade da marca, edite os templates relevantes.
Corrigir mensagens de erro confusas
Se os usuários reclamarem que uma mensagem específica está difícil de entender, localize o template pela chave ou pelo texto no campo de busca e reescreva com linguagem mais clara.
Adicionar orientações específicas
Em templates como boas-vindas ou seleção de empresa, você pode incluir instruções extras — por exemplo, listar os tipos de consulta disponíveis.
Restaurar padrão
O botão Restaurar padrão no formulário desfaz todas as customizações do template e volta ao texto original do sistema. Use quando uma edição causar problemas ou o template ficar desatualizado após uma atualização do sistema.
Antes de restaurar, copie o texto customizado se quiser guardar como referência — a ação não tem desfazer.
Inativar vs. Excluir
Os templates não podem ser excluídos — apenas inativados. Quando inativo, o sistema usa o texto padrão embutido. Isso garante que o IA Command sempre tenha uma mensagem de fallback para cada situação, mesmo que o template customizado esteja com problema.
