Teste de conexão
O que o teste faz
Envia uma mensagem de exemplo ao provedor usando a chave informada e verifica se a API responde. Um resultado com intenção e confiança confirma que a chave está válida.
Erros comuns
Chave inválida / Unauthorized: chave incorreta ou revogada — gere uma nova no painel do provedor.
Insufficient Balance: chave válida mas sem créditos — adicione saldo no painel do provedor.
Quota exceeded / Rate limit: limite do plano atingido. Aguarde a renovação ou faça upgrade.
Segurança das chaves
As chaves ficam armazenadas no servidor e nunca trafegam em claro para o cliente. Use o olhinho para verificar se digitou corretamente. Nunca compartilhe suas chaves.
As configurações são por empresa. Cada empresa tem suas próprias chaves e provedor primário.
Comportamento
Provedor primário
Provedor tentado primeiro para cada consulta. Se falhar, o sistema usa a ordem de fallback.
Ordem de fallback
Lista separada por vírgula com a sequência de provedores a tentar quando o primário falha. Provedores sem chave são pulados automaticamente.
Confiança mínima
Limiar para executar uma consulta automaticamente. Abaixo desse valor o sistema pede confirmação ao usuário antes de executar.
