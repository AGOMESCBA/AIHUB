O que é um Dataset

      
Um Dataset é um SELECT analítico completo que representa um conjunto de dados do ERP — faturamento, clientes, pedidos, etc. O motor do IA Command envolve esse SQL com filtros de período automaticamente ao executar.

    

    

      
Colunas da lista

      
Nome
Identificador do Dataset. Aparece na tela de Intenções quando você vincula.

      
ERP
Sistema ERP de origem dos dados (Protheus, SAP, Sankhya, etc.).

      
Limite
Número máximo de linhas que o Dataset retorna por consulta.

    

    

      
O que é o SQL Base

      
O SQL Base é um SELECT completo e analítico que você escreve uma vez. O motor do IA Command envolve automaticamente com filtros de período: SELECT TOP N * FROM (<seu_sql>) AS _base WHERE data >= @p0 AND data <= @p1. Quando o usuário pede agrupamento ("por produto", "por cliente"…), o motor gera GROUP BY no SQL Server: SELECT produto, SUM(valor) AS valor FROM (...) WHERE data >= @p0 GROUP BY produto ORDER BY valor DESC

      
Teste o SQL Base com o botão "Executar SQL" antes de salvar. Um Dataset com SQL inválido não funciona em produção.

    

    

      
Convenções obrigatórias

      

        
1. Aliases livres, resolução automática

        
Os aliases do SELECT podem estar em maiúsculo, minúsculo ou misto: AS DATA, AS data, AS Quantidade. O motor resolve o alias real antes de montar o SQL externo.

      

      

        
2. Não use TOP ou LIMIT

        
O motor adiciona SELECT TOP N * automaticamente com base no Limite configurado. Consultas com agrupamento dinâmico não têm TOP — o resultado é limitado pelo número de grupos.

      

      

        
3. Filtros de deletados (Protheus)

        
Inclua D_E_L_E_T_ = ' ' no WHERE de cada tabela do JOIN para excluir registros marcados como excluídos no Protheus.

      

      

        
4. Colunas métricas para GROUP BY dinâmico

        
Preencha Colunas métricas com as colunas numéricas separadas por vírgula (ex: valor,quantidade,margem). Quando o usuário perguntar "por produto" ou "por cliente", o motor gera GROUP BY com SUM() no SQL Server. Sem essa configuração o agrupamento ocorre em memória (fallback seguro, mas mais lento).

      

    

    

      
Regra local antes da IA

      
Antes de chamar IA, o IA Command tenta resolver a pergunta pelo proprio motor: equivalencias, intencoes, periodos, agrupamentos, limites e metricas do Dataset. O Dataset aumenta a pontuacao local quando expõe aliases claros e colunas metricas coerentes.

      
Exemplo: "Fat do ano por produto" combina "fat" nas equivalencias, "ano" no motor temporal, "produto" como agrupamento e a metrica faturamento no Dataset. Quando esses sinais fecham, a consulta executa localmente sem consumir tokens.

    

    

      
Fluxo recomendado

      
1. Crie o Dataset e escreva o SQL Base.
2. Defina o Campo Data (alias da coluna de data no SELECT).
3. Acesse Intenções e vincule esse Dataset à intenção correspondente.
4. Ative a intenção.

    

    

      
⚠️ Pontos de atenção

      

        
O período é filtro externo, não interno ao SQL

        
O motor não altera seu SQL — ele o envolve com WHERE campo_data BETWEEN @p0 AND @p1. O alias da coluna de data no SELECT deve ser idêntico ao configurado no campo Alias da coluna de data.

      

      

        
O sistema não agrega automaticamente no SQL

        
Se o SQL retornar múltiplas linhas (ex.: GROUP BY EMPRESA, DATA), o IA Command somará as colunas numéricas ao formatar a resposta. Para resultados mais precisos, faça a agregação final dentro do próprio SQL Base.

      

      

        
Aliases numéricos são somados automaticamente

        
Colunas com valores numéricos são somadas e exibidas na resposta. Exceção: colunas cujo nome começa ou termina com id, cod, num, seq, ano, mes ou dia são tratadas como identificadores e ignoradas. Use aliases descritivos como faturamento_total.

      

    

    

      
Detecção automática de dimensões

      
O sistema detecta automaticamente as colunas de cliente, produto, vendedor, fornecedor e empresa pelo nome do alias — sem configuração adicional. Use os nomes abaixo no SELECT para ativar agrupamento e filtros automáticos (vendas e compras).

      

        
DimensãoAliases aceitos automaticamente

        
          
📅 DataDATA, DT_*, DATA_*

          
🏢 ClienteCLIENTE, NM_CLI*, DS_CLI*, NOME_CLI*

          
📦 ProdutoPRODUTO, NEGOCIO, DS_PROD*, NM_PROD*, DESCR*

          
👤 VendedorVENDEDOR, NM_VEND*, DS_VEND*, COD_VEND*

          
🏪 FornecedorFORNECEDOR, NM_FORN*, DS_FORN*, NOME_FORN*, RAZAO*

          
🏭 EmpresaEMPRESA, FILIAL, UNIDADE

        
      

      
Nome fora do padrão? Adicione um alias no SELECT: RAZAO_SOCIAL AS cliente — e passa a funcionar automaticamente.

TipoExemplos de frases

        
          
📅 Hoje"hoje", "do dia", "agora"

          
📅 Ontem"ontem", "fat de ontem"

          
📅 Esta semana"essa semana", "esta semana"

          
📅 Semana passada"semana passada", "semana anterior"

          
📅 Mês atual"esse mês", "este mês", "do mês"

          
📅 Mês anterior"mês passado", "mês anterior"

          
📅 Ano atual"esse ano", "este ano", "YTD"

          
📅 Ano anterior"ano passado", "ano anterior"

          
📅 Último trimestre"último trimestre", "últimos 3 meses"

          
📅 Trimestres nomeados"Q1 do ano passado", "segundo trimestre deste ano", "1º tri", "Q3"

          
📅 Semestres"primeiro semestre", "H2 do ano passado", "2º semestre deste ano"

          
📅 Últimos N dias"últimos 7 dias", "últimas 2 semanas", "últimos 90 dias"

          
📅 Mês específico"fat de maio do ano passado", "março deste ano por produto"

          
📅 Acumulado"fat acumulado até maio do ano passado", "jan a abril deste ano"

          
📅 Personalizado"de 01/01 a 31/03", "entre março e junho de 2024"

        
      

    

    

      
Comparativos

      
Palavras como vs, versus, comparar, comparativo ativam o modo comparação. Sem essas palavras, a consulta retorna um único período.

      

        
TipoExemplos

        
          
Anual"fat deste ano vs ano passado", "comparar anos", "ano a ano"

          
Mensal"esse mês vs mês passado", "mês a mês"

          
Mesmo mês"fat de maio deste ano vs maio do ano passado"

          
Acumulado"acumulado até maio deste ano vs ano passado"

          
Genérico"fat do mês vs mesmo período do ano passado"

Colunas numéricas

      
Todas as colunas numéricas do resultado são somadas e exibidas. Exceção: colunas cujo nome começa ou termina com id, cod, num, seq, ano, mes ou dia são tratadas como identificadores e ignoradas.

      
Use aliases descritivos: faturamento_total, quantidade_vendida.

    

    

      
🔤 Equivalências de coluna

      
O sistema já vem com equivalências padrão para métricas comuns (tonelada, ton, volume, qtde, receita bruta, lucro, custo…), visíveis em Cadastros → Equivalências com o badge 🔒 Sistema. O campo Equivalência deve ser idêntico ao alias no SELECT deste Dataset — se o seu alias for diferente do padrão, edite o registro diretamente.

      

        
Usuário digitaEquivalência aponta paraCampo no SELECT

        
          
"valor de saída"faturamentoSUM(VLR) AS faturamento

          
"qtde", "volume", "ton"quantidadeSUM(QTD) AS quantidade

          
"lucro", "margem"margemSUM(MG) AS margem

        
      

      
Equivalências de Filtro normalizam valores de cliente, produto e vendedor — ex: apelido "CAIEIRINHA" → nome real "CAIEIRA LTDA". Esses são específicos da empresa e não vêm pré-cadastrados.

    

    

      
Resposta automática

      
O formatador adiciona automaticamente ao resultado:

      
% de participação no agrupamento
Quando o usuário pede "por produto" ou "por cliente", cada item mostra o % do total. Ex: Produto Aço — R$ 500k (32,1%)

      
Média diária
Para períodos de 8 dias ou mais, exibe a média por dia junto ao total. Ex: R$ 1.200.000 | Média: R$ 40.000/dia

📊 Camada Coluna

      
Use quando o usuário pede uma métrica com nome diferente do alias no SELECT deste Dataset. Os termos mais comuns (volume, qtde, ton, receita bruta, lucro, custo…) já vêm pré-cadastrados como 🔒 Sistema — verifique se o campo Equivalência bate com o alias do seu SELECT.

      

        
TermoEquivalência padrãoAlias no SELECT

        
          
volume, qtde, ton, tonelada…quantidadeSUM(QTD) AS quantidade

          
valor de saída, receita bruta…faturamentoSUM(VLR) AS faturamento

          
lucro, margem, markup…margemSUM(MG) AS margem

          
custo, cme, cmv…custoSUM(CME) AS custo

        
      

      
Se o alias no seu SELECT for diferente (ex: faturamento_total em vez de faturamento), edite o registro 🔒 Sistema correspondente e ajuste o campo Equivalência.
