Ajuda — Dataset SQL Base
Convenções obrigatórias
1. Aliases livres, resolução automática
Você pode escrever os aliases do SELECT em maiúsculo, minúsculo ou misto: AS DATA, AS data, AS Quantidade. O motor localiza o alias real e monta o wrapper com a caixa correta.
2. Não use TOP ou LIMIT
O motor adiciona SELECT TOP N * automaticamente com base no Limite configurado (padrão: 1000). Consultas com agrupamento dinâmico não têm TOP — o resultado é limitado pelo número de grupos, que naturalmente é pequeno.
3. Filtros de deletados (Protheus)
Inclua D_E_L_E_T_ = ' ' no WHERE de cada tabela do JOIN para excluir registros marcados como excluídos no Protheus.
4. Colunas métricas para GROUP BY dinâmico
Preencha Colunas métricas com as colunas numéricas separadas por vírgula (ex: valor,quantidade,margem). Quando o usuário perguntar "por produto" ou "por cliente", o motor gera GROUP BY no SQL Server com SUM() — muito mais eficiente do que agrupar em memória. Sem essa configuração o agrupamento ocorre em memória (fallback seguro, mas mais lento para grandes volumes).
Consulta normal: SELECT TOP 1000 * FROM (<seu SQL>) AS _base WHERE data >= @p0 AND data <= @p1
Com GROUP BY: SELECT produto, SUM(valor) AS valor FROM (<seu SQL>) AS _base WHERE data >= @p0 GROUP BY produto ORDER BY valor DESC
Regra local antes da IA
Antes de chamar IA, o sistema tenta resolver a pergunta com regras internas. O Dataset participa diretamente dessa decisao: aliases, campo de data e colunas metricas ajudam o motor a identificar periodo, agrupamento, metrica e ordenacao.
Como a pontuacao local fica forte
A pergunta ganha confianca quando encontra varios sinais juntos: equivalencia de intencao, periodo reconhecido, agrupamento como "por produto", metrica presente em Colunas metricas, filtro conhecido e limite/ranking. Se a confianca ficar alta, executa sem IA.
O que cadastrar no Dataset
Use aliases claros no SELECT e preencha Colunas metricas com os campos numericos que podem ser somados e ordenados. Ex: FATURAMENTO, QUANTIDADE. O usuario pode digitar em qualquer caixa; o motor resolve o alias real.
Exemplo: "Fat do ano por produto" encontra "fat" nas equivalencias, "ano" no motor temporal, "produto" no agrupamento e "FATURAMENTO" nas metricas do Dataset. Com isso, a regra local executa sem gastar tokens de IA.
O que é o SQL Base
O SQL Base é um SELECT completo e analítico que você escreve uma vez. O motor do IA Command envolve automaticamente com filtros de período: SELECT TOP N * FROM (<seu_sql>) AS _base WHERE campo_data BETWEEN @p0 AND @p1
Regras do SQL Base
1. SELECT completo e válido
Pode usar JOINs, subqueries, CTEs (WITH), funções de agregação. Não inclua TOP/LIMIT — o motor adiciona automaticamente.
2. Coluna de data com alias
O SELECT deve ter uma coluna de data com o mesmo alias definido em "Alias da coluna de data". Ex: F2_EMISSAO AS data.
3. Filtrar deletados (Protheus)
Sempre inclua WHERE D_E_L_E_T_ = ' ' para excluir registros marcados como excluídos.
4. Aliases em português
Prefira aliases descritivos: cliente, valor_total, data_emissao. A IA usa esses nomes ao compor a resposta.
5. Aliases de filtro automático
Para que filtros por produto, cliente e vendedor funcionem automaticamente, nomeie as colunas no SELECT com os aliases reservados: produto, cliente, vendedor, filial, status. Quando o usuário perguntar "fat do produto Aço 1020", o motor aplica automaticamente WHERE produto LIKE '%Aço 1020%'.
Executar SQL (preview)
O botão Executar SQL conecta à conexão ERP selecionada e retorna os primeiros 100 registros sem período — equivalente a ver a estrutura e dados brutos do Dataset. Use para validar aliases, JOINs e filtros antes de salvar.
Se o preview retornar erro, corrija o SQL antes de salvar. Um Dataset com SQL inválido não funciona em produção.
⚠️ Pontos de atenção
O período é aplicado como filtro externo, não dentro do seu SQL
O motor envolve seu SQL Base com WHERE campo_data BETWEEN @p0 AND @p1. Por isso, a coluna de data precisa aparecer no resultado do seu SELECT e ter o mesmo alias configurado no campo Alias da coluna de data. Se a coluna se chamar DT_EMISSAO no seu SELECT, configure o alias como DT_EMISSAO.
O sistema não agrega — seu SQL deve fazer isso
Se o seu SELECT tiver GROUP BY EMPRESA, DATA, o resultado pode trazer dezenas de linhas. O IA Command somará automaticamente as colunas numéricas ao montar a resposta, mas se você quiser uma única linha consolidada, faça a agregação completa no próprio SQL Base (sem GROUP BY por data).
O nome das colunas influencia o formato da resposta
O formatador de respostas lê os aliases do seu SELECT para montar a mensagem enviada ao WhatsApp. Colunas com prefixo id, cod, num, seq, ano, mes ou dia são tratadas como identificadores e não são somadas. Todas as demais colunas com valor numérico são somadas e exibidas. Use aliases descritivos: faturamento_total, valor_pedido.
Intenções com case específico têm prioridade
Algumas intenções (ex.: consultar_faturamento) têm formatação dedicada que exibe Total, Notas emitidas e Ticket médio. Quando a intenção vinculada não tem case específico, o sistema aplica a formatação genérica automática (soma das colunas numéricas). Verifique o nome exato da intenção na tela de Intenções.
