Ajuda — WhatsApp Services
Conceito
O que são WhatsApp Services?
Cada canal WhatsApp é registrado como um serviço Windows (via NSSM). Isso garante que os canais continuem funcionando mesmo que o navegador ou o sistema IAHub seja fechado — o Windows reinicia automaticamente o serviço em caso de falha.
Serviços instalados persistem entre reinicializações do servidor. Não é preciso iniciar manualmente após um restart do Windows.
Estados dos canais
● Conectado
Serviço ativo e WhatsApp autenticado. Mensagens estão sendo recebidas normalmente.
◌ Aguardando QR
Serviço iniciado, aguardando leitura do QR Code no celular para autenticar a sessão.
⏹ Parado
Serviço instalado mas parado. Clique em Iniciar para reativar sem precisar reinstalar.
⚠ Sem serviço
Canal cadastrado mas serviço Windows ainda não instalado. Use "Instalar e Iniciar".
Ações disponíveis
Instalar e Iniciar
Registra o canal no Windows Services via NSSM e inicia imediatamente. Exigido na primeira vez.
Iniciar
Inicia um serviço já instalado que estava parado.
Parar
Para o serviço sem desinstalá-lo. Pode ser reiniciado a qualquer momento.
Remover serviço
Desinstala o serviço do Windows. O canal continua cadastrado, mas precisará ser reinstalado para operar novamente.
