Passos:
1. Copie o código AdvPL abaixo e salve como IACommandAgent.prw no seu projeto Protheus.
2. Compile o fonte no Protheus IDE / TDS.
3. No rest.xml do seu ambiente, certifique-se de que o path /rest está habilitado.
4. Defina a API Key no próprio fonte (constante IAC_API_KEY) e recompile.
5. Use a mesma chave no campo "API Key" desta tela.

Ajuda — Conexões ERP
Modos de conexão
Direto (SQL Server / PostgreSQL)
O IA Command conecta diretamente ao banco de dados do ERP via TCP. Requer que ambos estejam na mesma rede ou VPN.
API Proxy (Protheus REST)
O IA Command envia o SELECT via HTTPS para um endpoint instalado no Protheus REST. Ideal para ambientes remotos ou em nuvem, sem abrir porta do banco.
Campos — Conexão Direta
Encrypt
Força criptografia TLS entre o IA Command e o SQL Server. Mantenha ativo em ambientes de nuvem.
Trust Cert
Aceita o certificado SSL do servidor sem validar com uma CA. Deve ficar marcado na maioria das instalações Protheus on-premise, que usam certificados auto-assinados.
Protheus on-premise → marque Trust Cert. SQL Server em nuvem com certificado válido → pode desmarcar.
Status das conexões
● Ativa
Esta é a conexão padrão da empresa. Apenas uma pode estar ativa. Os Datasets usam esta conexão para executar queries.
Testar conexão
Verifica se o IA Command consegue se comunicar com o banco. Para conexão direta testa o login; para API Proxy faz um GET no endpoint /ping.
Sempre teste a conexão antes de ativá-la. Uma conexão ativa com falha impede todas as consultas dos usuários.
Boas Práticas de Segurança
Usuário somente leitura
Crie um login SQL com permissão apenas de SELECT nas tabelas que serão consultadas. O IA Command nunca precisa de INSERT, UPDATE ou DELETE.
