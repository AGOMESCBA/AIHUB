Ajuda — Diálogos Conversacionais
O que são
Diálogos são respostas automáticas locais. O sistema verifica padrões cadastrados aqui antes de chamar a IA externa — economiza tokens e garante resposta mesmo quando Groq, Gemini ou DeepSeek estão fora do ar.
Sem diálogos: cliente envia "Boa noite!" e recebe um erro técnico. Com diálogos: recebe "Olá! Sou o IA Command. Como posso te ajudar?" — sempre.
Fluxo de resposta
1. Mensagem chega → sistema verifica padrões de diálogo.
2. Padrão encontrado → responde imediatamente (não chama a IA).
3. Nenhum padrão → chama IA externa (Groq, Gemini, DeepSeek…).
4. IA responde → envia o resultado normalmente.
5. IA falha → envia mensagem amigável de instabilidade e registra em "Não Respondidas".
Campos
Título
Nome interno do diálogo — só para organização. O cliente não vê. Ex: "Saudações gerais".
Tipo
Categoria (Saudação, Despedida, Agradecimento, Ajuda, Confusão, Outro). Não afeta o comportamento — serve para agrupar na listagem.
Padrões de disparo
Palavras ou frases que ativam este diálogo. O sistema verifica se a mensagem do cliente contém algum deles (ignora maiúsculas e acentos). Digite e pressione Enter ou vírgula para confirmar cada padrão.
Resposta
Texto enviado ao cliente. Suporta formatação WhatsApp: *negrito*, _itálico_, ~tachado~.
Prioridade
Número de 0 a 100. Diálogos com maior prioridade são verificados primeiro. Use para que um diálogo da empresa sobreponha um global. Padrões do sistema têm prioridade 10.
Origem
Preenchido automaticamente. Padrão = instalado pelo sistema para esta empresa, pode ser editado mas não excluído. Personalizado = criado pela empresa.
Status
Ativo = em uso. Inativo = ignorado (sem excluir — você pode reativar depois).
Não Respondidas
Toda mensagem que nem os diálogos nem a IA conseguiram responder fica registrada aqui. Clique em Promover para transformar a mensagem em um novo diálogo com um clique.
Revise essa aba periodicamente. Com o tempo, a base de diálogos cresce com as dúvidas reais dos seus clientes.
Registros protegidos
Diálogos de origem Padrão são protegidos contra exclusão — cada empresa tem os seus. Para desativá-los, altere o status para Inativo. Para restaurar os textos originais, use o botão Restaurar padrões.
