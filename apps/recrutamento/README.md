# IA Recruit

A inteligencia que encontra os talentos certos.

Projeto do sistema de recrutamento da plataforma IA Hub.

Responsabilidades:
- dashboard de recrutamento
- curriculos
- vagas
- funcoes
- analise de curriculos
- monitores de WhatsApp/e-mail
- integracoes especificas
- configuracoes especificas

O acesso deve ser validado pela sessao emitida pelo IA Hub Shell.
