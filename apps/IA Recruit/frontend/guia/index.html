Objetivo do Sistema

O que o IAHub resolve e por que ele faz diferença no recrutamento.

IAHub Plataforma de Recrutamento com Inteligência Artificial ▾
"Não busca palavras — entende candidatos."
O IAHub vai além da triagem por palavras-chave. Ele compreende o contexto, reconhece equivalências de termos e entrega uma pontuação objetiva e auditável para cada candidato — eliminando a subjetividade do processo seletivo.
O problema que o IAHub resolve

O recrutamento tradicional consome horas de triagem manual, sofre vieses inconscientes e perde bons candidatos por diferenças de vocabulário. Um currículo que diz "Gestão de Pessoas" e uma vaga que exige "Recursos Humanos" são ignorados pelos sistemas convencionais — mas não pelo IAHub.

Captação automática por múltiplos canais
Currículos chegam pelo WhatsApp, e-mail IMAP ou formulário público — e são processados automaticamente pela IA assim que recebidos. Nenhuma intervenção manual necessária para a coleta.
Análise com equivalência semântica de termos
A IA reconhece que "SoftExpert" = "SE Suite", "CLT" = "carteira assinada", "Excel avançado" inclui "Power BI". O candidato não é penalizado por usar terminologia diferente — o sistema entende o significado, não apenas a palavra.
Pontuação objetiva: 100 pontos de clareza
Cada candidato recebe uma nota de 0 a 100, distribuída em quatro critérios mensuráveis. O recrutador vê exatamente por que cada candidato recebeu aquela pontuação — pontos fortes listados, lacunas identificadas, resumo gerado pela IA.
Do recebimento ao Softexpert — sem planilhas
O fluxo completo é gerenciado dentro do sistema: captação → análise → seleção de finalistas → envio direto ao processo seletivo no Softexpert com currículo em PDF e nota de aderência registrados automaticamente.
Quatro pilares do IAHub

🏢
Multiempresa

🔗

Envio automático de candidatos, currículos e notas de aderência diretamente para o Softexpert — sem re-digitação.

Tecnologia

Stack técnica e integrações que sustentam a plataforma.

Stack Arquitetura e Componentes Técnicos ▾
Servidor e Backend
Node.js + Express
Servidor de aplicação JavaScript de alta performance. Gerencia todas as rotas da API, autenticação, sessões e lógica de negócio dos módulos.
Socket.IO
Comunicação em tempo real via WebSocket. Utilizado nos monitores de WhatsApp e e-mail para transmitir logs ao vivo para o browser sem necessidade de recarregar a página.
Windows Server + NSSM + Nginx
O IAHub roda como serviço Windows gerenciado pelo NSSM (reinício automático em falhas). O Nginx atua como proxy reverso, gerenciando HTTPS e roteamento.
Frontend
HTML + CSS + JavaScript estático
Interface construída sem frameworks (sem React, Vue ou Angular). Cada tela é um arquivo HTML independente com JS inline — resultando em carregamento instantâneo e zero overhead de framework.
Tabulator (via CDN)
Biblioteca de grade de dados usada nas telas com listagens. Oferece filtros por coluna, agrupamento drag-and-drop e ordenação — tudo configurável por parâmetros.
Design System com CSS Custom Properties
Todas as cores, espaçamentos e transições são definidos via tokens (var(--accent), var(--bg-card), etc.) — permitindo consistência visual em toda a plataforma e suporte a temas.
Captura de Currículos
whatsapp-web.js
Biblioteca open source gratuita que automatiza o WhatsApp Web via Chrome headless. Permite receber PDFs enviados pelos candidatos sem custo de API. Autenticação via QR Code.
API Oficial Meta (WhatsApp Business)
Alternativa paga para uso comercial intenso. Sem QR Code, sem risco de bloqueio. Recebe mensagens via webhook HTTPS direto dos servidores da Meta.
IMAP (e-mail)
Protocolo padrão de acesso a caixas de e-mail. O monitor verifica a caixa configurada em intervalos regulares e processa automaticamente os anexos PDF recebidos.
Extração de texto PDF
O sistema lê o conteúdo textual do PDF antes de enviar à IA. PDFs protegidos por senha ou baseados em imagem escaneada sem OCR não são processados — o candidato é notificado automaticamente.
Persistência
Banco de dados JSON em disco
Cada empresa tem seu arquivo apps/IA Recruit/data/empresa_ID.json com todas as suas tabelas lógicas (currículos, vagas, funções, análises). Sem banco SQL — toda a lógica de consulta e gravação é feita em memória pelo servidor Node.
Segurança
bcryptjs + express-session
Senhas armazenadas com hash bcrypt (fator de custo 10). Sessões gerenciadas em arquivo no servidor — sem tokens JWT expostos no cliente.
Rate Limiting
Limite de requisições por IP para proteção contra força bruta nas rotas de autenticação.
Integração Nativa com Softexpert (SE Suite)
🔗
Integração Nativa com o Softexpert — sem intermediários
O IAHub se comunica diretamente com a API REST e os Web Services SOAP do SE Suite
Envio de Candidatos e Currículos principal
Ao encerrar uma análise, o IAHub cria automaticamente o candidato no processo seletivo do SE, anexa o PDF original do currículo e registra a nota de aderência calculada pela IA — tudo via API, sem re-digitação.
Sincronização de Vagas
As vagas do IAHub são espelhadas nos processos seletivos do SE. O vínculo candidato ↔ vaga fica correto em ambos os sistemas automaticamente.
Sincronização de Funções (Cargos)
O catálogo de funções do IAHub é sincronizado com os cargos cadastrados no SE, mantendo os IDs de referência consistentes entre os dois sistemas.
Configurador de API
Interface dedicada (SE API Configurador) para definir a URL do servidor SE, usuário, senha e testar a conexão antes de qualquer envio. Cada empresa pode ter suas próprias credenciais de integração.
Rastreabilidade completa
Cada envio ao SE gera um registro de log com: status (Sucesso / Erro / Parcial / Revertido), XML enviado, resposta da API, etapas executadas e timestamp. Auditoria total de todas as integrações realizadas.

Inteligência Artificial

Onde, como e quais IAs o sistema utiliza em cada etapa do processo.

IA Modelos, Funções e Fallback Automático ▾
Os dois modelos de IA utilizados
PRIMÁRIO
Groq — Llama 3.3 70B
Motor de inferência ultrarrápido da Groq com o modelo Llama 3.3 de 70 bilhões de parâmetros. Processa cada currículo em segundos — ideal para análises em lote de alto volume. Plano gratuito com limite de taxa por minuto.
FALLBACK
Google Gemini 2.0 Flash
Acionado automaticamente quando o Groq atinge o limite de taxa (erro 429) ou quando a quota é excedida. Garante continuidade da análise sem intervenção manual e sem perder candidatos por falha técnica.
🛡️ Política de resiliência: se ambos os provedores falharem simultaneamente, o candidato recebe automaticamente um score neutro igual ao corte mínimo configurado — não é eliminado. O processo continua e o recrutador é informado para revisar manualmente aquele candidato.
Onde a IA atua no sistema
ETAPA 1
Recebimento do Currículo (WhatsApp / E-mail)
Detecção de idioma e tradução automática
Identifica o idioma do PDF recebido. Se não estiver em português, traduz integralmente antes de processar — garantindo que candidatos internacionais sejam analisados corretamente.
Validação: é um currículo?
Verifica se o documento é de fato um currículo. Contratos, comprovantes, procurações e outros documentos são rejeitados — o candidato recebe uma mensagem explicativa automaticamente.
Extração de dados estruturados
Lê o texto do PDF e extrai: nome completo, e-mail, telefone, experiências profissionais (empresa, cargo, período, responsabilidades), formação acadêmica e habilidades técnicas.
ETAPA 2
Análise de Aderência à Vaga
Pontuação por quatro critérios (0–100 pts)
A IA avalia cada candidato individualmente: Requisitos Obrigatórios (até 50 pts), Desejáveis (até 30 pts), Formação (até 10 pts) e Habilidades (até 10 pts). Pontuação proporcional — sem penalidades por ausência.
Equivalência semântica de termos
A IA não compara palavras literalmente — ela entende significado. "SoftExpert" = "SE Suite", "Gestão de Pessoas" = "Recursos Humanos", "Excel Avançado" pode cobrir "Power BI". O candidato não é punido por terminologia diferente.
Identificação de pontos fortes e lacunas
Para cada candidato, a IA lista os requisitos que o candidato atende (✓) e os que estão ausentes ou parciais (●) — dando ao recrutador contexto imediato sem precisar ler o currículo completo.
Resumo explicativo personalizado
A IA gera um parágrafo em linguagem natural explicando a compatibilidade do candidato com a vaga — baseado no perfil real do currículo, não em templates genéricos.
ETAPA 3
Cálculo Determinístico de Experiência
Antes de enviar à IA, o sistema calcula automaticamente o tempo total de carreira de cada candidato somando os períodos das experiências profissionais. Suporta os formatos mais comuns: DD/MM/YYYY, MM/YYYY, apenas ano ("2020"), "desde MM/YYYY", "atual" e similares. Esse cálculo é feito de forma determinística pelo servidor — sem custo de IA — e é exibido como dado complementar na análise.
💡 Todas as chamadas de IA passam por um módulo central (modules/ia/index.js) que gerencia automaticamente o roteamento entre provedores, o controle de fallback e o registro de consumo de tokens — visível no Dashboard.

Administração do Sistema

Configure as empresas, a identidade visual, os usuários e seus níveis de acesso antes de iniciar a operação.

1.1 Cadastro de Empresas ▾

O ponto de partida do sistema é o cadastro das empresas. Cada empresa possui seus próprios currículos, vagas, configurações e candidatos — completamente isolados das demais. Acesse Configurador → Administração → aba Empresas.

Razão Social obrigatório
Nome oficial da empresa ou produtor rural. É exibido no seletor de empresa do cabeçalho do sistema.
CPF / CNPJ obrigatório
Documento de identificação da empresa. O sistema aplica máscara automaticamente conforme o número de dígitos informado.
Telefone
Telefone de contato principal da empresa. Apenas para referência cadastral.
E-mail
E-mail institucional de contato. Não é usado para envio automático — apenas informativo.
Site
Endereço do site da empresa (com https://). Campo opcional para referência.
Endereço
Endereço físico da empresa no formato livre (Rua, número, cidade – UF). Campo opcional.
💡 Após salvar o cadastro da empresa, a aba Identidade Visual é liberada para configurar o logo e a imagem da tela de login (etapa 1.2).

1.2 Identidade Visual (Tela de Login) ▾

Cada empresa pode ter sua própria identidade visual na tela de login — logo próprio, imagem de fundo lateral e frase institucional. Acesse Administração → Empresas → editar empresa → aba Identidade Visual.

Logomarca
Imagem PNG, JPG ou WebP com o logo da empresa. Aparece no centro do painel de login. Recomendado: fundo transparente, proporção quadrada ou retangular com no mínimo 200px.
Imagem lateral
Imagem de fundo que ocupa o lado esquerdo da tela de login. Recomendado: formato 16:9 ou retrato, mínimo 800px de altura. Pode ser foto institucional, paisagem ou imagem da marca.
Texto sobre a imagem lateral
Frase ou slogan institucional exibido em destaque sobre a imagem lateral. Máximo 180 caracteres. Exemplo: "Conectando talentos ao futuro."
⚠️ A aba Identidade Visual só é liberada após salvar os dados cadastrais da empresa (etapa 1.1). Enquanto não configurada, o sistema exibe o padrão padrão do IAHub no login.

1.3 Cadastro de Usuários ▾

Crie os usuários que terão acesso ao sistema. Um usuário pode estar vinculado a uma ou mais empresas com perfis de acesso diferentes em cada uma. Acesse Configurador → Administração → aba Usuários.

Nome completo obrigatório
Nome de exibição do usuário no sistema. Aparece no cabeçalho após o login.
Usuário (login) obrigatório
Identificador único de acesso. Recomendado no formato nome.sobrenome (sem espaços, sem acentos). Não pode ser alterado após criação.
Celular obrigatório
Número de celular com DDD. Utilizado para contato e identificação do usuário.
E-mail obrigatório
Endereço de e-mail do usuário. Deve ser único no sistema.
Perfil obrigatório
Admin — acesso total ao sistema, sem restrições de rotina. Usuário — acesso limitado às rotinas que lhe forem concedidas na etapa 1.4.
Status
Ativo ou Inativo. Usuários inativos não conseguem fazer login. Disponível apenas na edição de usuários já existentes.
Senha obrigatório
Mínimo de 8 caracteres. Na edição, o campo é opcional — deixe em branco para manter a senha atual.
💡 Usuários com perfil Admin têm acesso irrestrito a todas as rotinas e empresas — não é necessário configurar permissões para eles (etapa 1.4).

1.4 Permissões de Acesso ▾

Após criar o usuário, defina quais rotinas ele pode acessar em cada empresa. O controle é por rotina individual — o usuário só enxerga no menu o que lhe foi liberado. Acesse Administração → Usuários → selecione o usuário → painel Acessos.

Painel esquerdo — Empresas
Lista todas as empresas cadastradas. Clique em uma empresa para visualizar e editar as rotinas liberadas para aquele usuário naquela empresa. O círculo azul indica que o usuário já possui algum acesso nessa empresa.
Painel direito — Rotinas
Exibe as rotinas agrupadas por módulo (Monitores, Recrutamento, Analisador, Integrações, Configurador). Marque o checkbox do grupo para liberar/remover todas as rotinas do módulo de uma vez, ou marque individualmente.
Botões Marcar todos / Desmarcar todos
Atalhos para conceder ou revogar todas as rotinas de todas as empresas de uma vez. Use com cuidado.
⚠️ Usuários com perfil Admin ignoram as permissões — sempre têm acesso total. O painel de permissões para admins exibe um aviso informando isso e não permite alteração.

Configuração Técnica da Empresa

Configure os canais de recepção de currículos, os parâmetros de IA e a integração com o Softexpert para cada empresa.

2.1 Parâmetros Gerais e IA ▾

Configure os parâmetros globais do sistema e as chaves de IA. Acesse Configurador → Configurações. As configurações são globais — valem para todas as empresas.

Identificação do Sistema
Nome exibido no rodapé
Nome do sistema exibido no rodapé das telas. Padrão: IAHUB.
Frase do sistema
Subtítulo ou slogan exibido no rodapé. Ex.: Onde a gestão encontra a inteligência.
Versão / Release
Número de versão do sistema exibido na interface. Apenas informativo.
Inteligência Artificial — Groq (principal)
Chave de API (Groq) obrigatório
Chave obtida em console.groq.com. É o motor principal de análise de currículos. Sem essa chave o analisador não funciona.
Limite de tokens/mês (Groq)
Teto de consumo mensal de tokens do Groq. Usado para acompanhamento no dashboard. Coloque 0 para sem limite.
Limite US$ (Groq)
Teto de custo mensal em dólares para o Groq. Exibido no dashboard de consumo.
Inteligência Artificial — Google Gemini (fallback)
Chave de API (Gemini)
Chave obtida no Google AI Studio. Usada automaticamente quando o Groq falha ou atinge o limite. Opcional.
Modelo Gemini
Identificador do modelo Gemini a usar. Padrão: gemini-1.5-flash. Consulte a documentação do Google para modelos disponíveis.
Classificação de Senioridade
Limite Júnior → Pleno (meses)
Tempo de experiência (em meses) a partir do qual o candidato é classificado como Pleno. Padrão: 12 meses.
Limite Pleno → Sênior (meses)
Tempo de experiência a partir do qual o candidato é classificado como Sênior. Padrão: 36 meses.
💡 As chaves de API são armazenadas de forma protegida. O campo exibe •••••••• após salvar — isso é normal e não significa que o valor foi perdido.

2.2 Configuração de E-mail IMAP ▾

Configure a caixa de e-mail que o sistema monitorará para capturar currículos enviados por e-mail. Acesse Configurador → Configurações → aba E-mail. Cada empresa tem sua própria configuração de e-mail.

Tipo de Servidor obrigatório
Selecione o provedor: Gmail, Outlook/Hotmail, Yahoo ou Outro. Ao selecionar um provedor conhecido, os campos de host e porta são preenchidos automaticamente.
Endereço de E-mail obrigatório
E-mail corporativo que receberá os currículos. Ex.: recrutamento@empresa.com.br. Este e-mail será monitorado pelo sistema.
Senha do App (App Password) obrigatório
Para Gmail e Outlook com autenticação em dois fatores ativa, use uma senha de aplicativo gerada nas configurações de segurança da conta — não a senha normal. Para outros provedores, a senha normal pode funcionar.
Host IMAP / Porta IMAP / Segurança IMAP
Preenchidos automaticamente para Gmail (imap.gmail.com:993) e Outlook. Para outros provedores, preencha manualmente com os dados fornecidos pelo provedor de e-mail.
Host SMTP / Porta SMTP / Segurança TLS
Configurações do servidor de envio. Usado para notificações e respostas automáticas. Preenchido automaticamente para Gmail (smtp.gmail.com:465).
Intervalo de Verificação (minutos)
Frequência com que o monitor verificará a caixa de entrada em busca de novos e-mails. Padrão: 2 minutos. Mínimo: 1 minuto.
⚠️ Para Gmail, é obrigatório habilitar IMAP nas configurações da conta e gerar uma Senha de Aplicativo (não a senha normal). O acesso IMAP pode estar desativado por padrão em contas corporativas Google Workspace.

2.3 Configuração do WhatsApp ▾

Configure o número de WhatsApp que receberá os currículos dos candidatos e as mensagens automáticas que o sistema enviará em cada situação. Acesse Configurador → Configurações → aba WhatsApp.

Identificação do Número
Identificação / Nome do Número
Nome de referência interno para este número. Ex.: RH — Empresa XYZ. Ajuda a identificar o canal no painel de monitores.
Número de Destino
Número que receberá notificações quando um currículo for processado com sucesso. Formato internacional sem símbolos: 5511999999999. Pode ser o número do RH responsável.
Mensagens Automáticas
✅ Currículo recebido com sucesso
Mensagem enviada ao candidato quando o PDF do currículo é recebido e processado corretamente.
⚠️ Arquivo não é PDF
Enviada quando o candidato envia um arquivo que não está em formato PDF (ex.: Word, imagem).
❌ PDF ilegível ou protegido
Enviada quando o PDF enviado está corrompido, protegido por senha ou é um scan de imagem sem texto reconhecível.
😊 Documento não é um currículo
Enviada quando o PDF é legível mas a IA identifica que não se trata de um currículo.
⚠️ Currículo duplicado — use {nome}
Enviada quando já existe um currículo cadastrado com o mesmo telefone ou e-mail. O placeholder {nome} é substituído pelo nome do candidato já cadastrado.
😊 Candidato optou por NÃO atualizar
Enviada quando o candidato responde que não deseja substituir o currículo existente.
❌ Erro ao processar currículo
Mensagem de erro genérico quando ocorre uma falha inesperada no processamento.
💡 As mensagens suportam formatação WhatsApp: *negrito*, _itálico_ e quebras de linha. Personalize o tom de acordo com a cultura da empresa.

2.4 SE API Configurador ▾

Configure a integração com o Softexpert definindo templates XML, mapeamento de campos e flows de execução. Esta etapa habilita o envio de candidatos ao SE. Acesse Integrações → SE API Configurador.

Conexão com o Softexpert (em Configurações → aba SE)
URL do Webservice (SOAP) obrigatório
Endereço do serviço SOAP do Softexpert. Formato: https://suaempresa.softexpert.com/se/ws/fm_ws.php?wsdl. Fornecido pelo administrador do SE.
Token de Autenticação (JWT) obrigatório
Token JWT gerado no painel de administração do Softexpert. Necessário para autenticar as chamadas da API.
ID do campo — Empresa / Nome da Empresa
Identificadores dos campos personalizados no formulário do SE que receberão o código e o nome da empresa. Ex.: IDEMP e NMEMP. Deixe em branco para não enviar esses campos.
SE API Configurador — Estrutura
Templates XML
Modelos de payload SOAP com placeholders ({{nome}}, {{cargo}}, etc.). Cada template representa um tipo de chamada ao SE, como iniciar um workflow ou registrar um currículo.
Configurações
Vinculam um template a um endpoint e definem o mapeamento de campos — quais dados do IAHub preenchem quais placeholders do XML. Também definem onde salvar o ID de workflow retornado pelo SE.
Flows
Sequência ordenada de configurações executadas em cascata. Permitem encadear múltiplas chamadas ao SE em uma única ação, como criar o candidato e iniciar o processo seletivo em sequência.
⚠️ Esta etapa requer conhecimento da estrutura de formulários e workflows do Softexpert. Envolva o administrador do SE para obter os IDs de campos, endpoints e estrutura dos XMLs.

Monitores e Recebimento de Currículos

Suba os serviços de monitoramento e acompanhe o recebimento de currículos pelos canais configurados.

4.1 Subida dos Monitores (WhatsApp e E-mail) ▾

Com as configurações técnicas concluídas (Fase 2), é hora de iniciar os monitores para que o sistema comece a capturar currículos em tempo real. Acesse Monitores → Monitores para ver o painel central com todos os monitores por empresa.

Painel de Monitores

O painel exibe um card por empresa com o status atual do monitor WhatsApp e do monitor E-mail. A partir daqui você acessa cada monitor com um clique.

Status do monitor
Indicador em tempo real: Rodando (ponto verde) quando o serviço está ativo e recebendo mensagens, ou Parado (ponto cinza) quando inativo.
Botão Abrir Monitor WhatsApp
Abre a tela de controle do monitor WhatsApp daquela empresa, onde é possível iniciar/parar o serviço e escanear o QR Code.
Botão Abrir Monitor E-mail
Abre a tela de controle do monitor de e-mail IMAP daquela empresa, com log em tempo real das verificações.
Monitor WhatsApp — passo a passo
1. Iniciar o serviço
Clique em ▶ Iniciar Serviço. O Chrome sobe em segundo plano no servidor e o log começa a exibir as mensagens de inicialização.
2. Abrir o painel QR Code
Clique em 📱 QR Code para abrir o painel lateral. Aguarde alguns segundos até o QR Code aparecer na tela.
3. Escanear com o celular
No celular com o número que receberá os currículos: WhatsApp → Menu (⋮) → Dispositivos conectados → Conectar dispositivo. Aponte a câmera para o QR Code exibido na tela do sistema.
4. Conexão estabelecida
O painel exibe ✅ WhatsApp conectado! e o status muda para Rodando. A partir deste momento, todo PDF enviado para o número é processado automaticamente pela IA.
💡 Sessão persistente: Após o primeiro escaneamento, a sessão é salva no servidor. Nas próximas vezes que o serviço for iniciado, ele reconecta automaticamente sem precisar escanear novamente — desde que o número não tenha sido desconectado pelo celular.
⚠️ O WhatsApp utilizado é baseado em whatsapp-web.js (solução não-oficial, gratuita). Para uso comercial intenso, ative a API Oficial Meta em Configuração do WhatsApp — nesse modo não há QR Code e a autenticação é via token permanente.
Monitor E-mail IMAP — passo a passo
1. Verificar configuração ativa
O painel lateral direito mostra a conta, servidor IMAP e intervalo de verificação configurados na etapa 2.2. Confirme que as informações estão corretas antes de iniciar.
2. Iniciar o serviço
Clique em ▶ Iniciar Serviço. O sistema começa a verificar a caixa de entrada no intervalo configurado (ex.: a cada 3 minutos). O log exibe cada verificação em tempo real.
3. Acompanhar estatísticas
O painel lateral exibe E-mails hoje (recebidos na sessão atual) e Total recebidos (histórico acumulado da empresa).
💡 O monitor de e-mail processa automaticamente anexos PDF recebidos na caixa configurada. E-mails sem anexo PDF são ignorados. Se o PDF não for um currículo válido, o registro não é salvo.

4.2 Recebimento e Visualização de Currículos ▾

Conforme os candidatos enviam seus currículos pelo WhatsApp ou e-mail, os registros aparecem automaticamente nas telas de acompanhamento. Acesse Recrutamento → Currículos para ver a lista completa.

O que acontece quando um candidato envia o currículo?
1. Recebimento e validação
O sistema verifica se o arquivo recebido é um PDF. Outros formatos (imagens, áudio, texto simples) são ignorados e o candidato recebe uma orientação automática.
2. Extração e verificação
O texto do PDF é extraído. A IA verifica se o idioma é português (traduz automaticamente caso contrário) e se o conteúdo é de fato um currículo.
3. Análise e salvamento
A IA extrai os dados estruturados (nome, e-mail, telefone, experiências profissionais, formação acadêmica, habilidades) e salva o registro. O candidato recebe uma confirmação de recebimento no WhatsApp ou por e-mail.
4. Detecção de duplicatas
Se já houver um currículo com o mesmo e-mail ou telefone, o candidato é consultado via mensagem automática sobre atualização (SIM substitui o anterior, NÃO mantém o registro existente).

Detalhe do currículo
Clique em qualquer linha para abrir o perfil completo: dados pessoais, experiências profissionais (empresa, cargo, período, responsabilidades), formação acadêmica e habilidades extraídas pela IA.

Análise de Currículos e Integração

Execute a análise de aderência com IA, avalie os resultados e envie os candidatos aprovados para o Softexpert.

5.1 Execução do Analisador de Currículos ▾

O Analisador compara todos os currículos recebidos com o perfil de uma vaga específica, atribuindo uma pontuação de compatibilidade (0–100 pontos) a cada candidato. Acesse Analisador de Currículos → Analisador.

Passo a passo da análise
1. Selecionar a vaga
No campo Vaga, escolha a vaga que deseja analisar. O sistema exibe o contexto completo da vaga selecionada — função, requisitos obrigatórios, desejáveis e habilidades. Confirme as informações antes de prosseguir.
2. Definir filtro de currículos (opcional)
Por padrão o sistema analisa todos os currículos da empresa. Se a vaga tiver candidatos vinculados via Processo Seletivo (formulário público), é possível selecionar Apenas desta vaga para restringir a análise a esse grupo.
3. Clicar em "Analisar Currículos"
O sistema processa cada currículo individualmente: calcula o tempo de carreira de forma determinística, envia o texto completo à IA junto com o perfil da função e aguarda a pontuação por critério.
4. Acompanhar o progresso
Uma barra de progresso indica quantos currículos já foram processados. Cada candidato é analisado em sequência — o tempo total varia conforme o volume de currículos e a velocidade da IA.
Como a pontuação é calculada

A pontuação máxima é 100 pontos, distribuída em quatro critérios. Não há penalidade por ausência — candidatos que não atendem um critério simplesmente não ganham esses pontos.

Requisitos Obrigatórios até 50 pts
Critérios essenciais da função. A pontuação é proporcional: (requisitos atendidos ÷ total de requisitos) × 50. Exemplo: atende 3 de 4 requisitos obrigatórios → 37,5 pts.
Requisitos Desejáveis até 30 pts
Diferenciais valorizados, porém não obrigatórios. Pontuação proporcional ao que o candidato apresenta.
Formação Acadêmica até 10 pts
Grau de instrução e área de formação versus o definido na Função. Atende ou supera = 10 pts; próxima da área = parcial; não atende = 0 pts.
Habilidades Técnicas até 10 pts
Ferramentas e tecnologias listadas na função. A IA considera equivalências (ex: "SoftExpert" = "SE Suite"). Pontuação proporcional ao domínio demonstrado.
💡 Os pesos de cada critério e a pontuação mínima de aprovação (padrão: 50 pts) são configuráveis em Analisador de Currículos → Configuração → Pesos de Pontuação.
💡 Fallback automático de IA: a análise usa Groq (Llama 3.3 70B) como primário. Se ocorrer limite de taxa, o sistema troca automaticamente para Gemini 2.0 Flash. Se ambos falharem, o candidato recebe score neutro igual ao corte mínimo e não é eliminado.

5.2 Resultados e Encerramento da Análise ▾

Após a IA concluir o processamento, os candidatos são exibidos ordenados do maior para o menor score. O recrutador revisa, marca os finalistas e encerra a análise para registrá-la no histórico e liberar o envio ao Softexpert.

Como ler os resultados
Resumo geral
Painel com 5 contadores: total analisado, aprovados (acima do corte), desclassificados (abaixo do corte), finalistas marcados e tempo médio de carreira do grupo.
Cards de candidatos aprovados
Cada candidato exibe: ranking (posição na lista), score total (0–100), barra de compatibilidade colorida (verde ≥ 70 / amarelo 50–69), pontuação detalhada por critério, pontos fortes (✓) e lacunas (●) identificados pela IA e resumo textual do candidato em relação à vaga.
Candidatos desclassificados
Exibidos em seção colapsada ao final da página, com nome, contato e motivo (pontuação obtida vs. corte mínimo). Clique em Mostrar desclassificados para visualizar.
Filtro por compatibilidade
Use o seletor lateral para filtrar apenas candidatos de Alta compatibilidade (70–100 pts) ou Média compatibilidade (50–69 pts), facilitando a triagem quando houver muitos aprovados.
Marcar finalistas e encerrar
Marcar candidatos finalistas
Use o checkbox em cada card (ou Marcar todos na barra lateral) para selecionar os candidatos que irão para a próxima etapa. Os cards selecionados recebem destaque visual em azul.
Encerrar Análise da Vaga obrigatório para envio ao SE
Clique em Encerrar Análise da Vaga na barra inferior para salvar os resultados no Histórico de Análises. Apenas após o encerramento os candidatos ficam disponíveis para envio ao Softexpert (etapa 5.3).
⚠️ O ID da análise é único por vaga e por dia. Rodar a análise novamente no mesmo dia exibe um aviso de confirmação antes de sobrepor os resultados anteriores.
💡 O Histórico de Análises (Analisador → Histórico) mantém registro de todas as análises realizadas. É possível consultá-las, comparar rodadas e regenerar a qualquer momento.

5.3 Envio ao Softexpert (SE Integrações) ▾

Com a análise encerrada e os finalistas marcados, o próximo passo é enviar os candidatos aprovados para o processo seletivo no Softexpert. Acesse Integrações → SE Integrações.

O que o SE Integrações faz

A tela centraliza três fluxos de envio ao Softexpert: vagas, funções e currículos. Para o fluxo de recrutamento, o mais usado é o envio de currículos dos finalistas vinculados à vaga.

SE Currículos
Envia os candidatos finalistas de uma análise para o processo seletivo correspondente no Softexpert. O sistema usa a API REST do SE para criar o candidato, associar o currículo em PDF e registrar a pontuação de aderência como nota.
SE Vagas
Sincroniza as vagas do IAHub com os processos seletivos do Softexpert, criando ou atualizando o registro de vaga no SE. Necessário para que o vínculo candidato ↔ vaga fique correto no SE.
SE Funções
Sincroniza o catálogo de funções (cargos) do IAHub com os cargos cadastrados no Softexpert, mantendo os IDs de referência atualizados.
Passo a passo — enviar currículos ao SE
1. Acessar SE Currículos
Em Integrações → SE Integrações, acesse a aba SE Currículos. A tela exibe o histórico de todos os envios anteriores com status individual (Sucesso, Erro, Parcial, Revertido).
2. Verificar a configuração ativa
O banner superior exibe o modo de envio configurado. Confirme que o SE API Configurador está correto (URL do servidor SE, usuário e senha) antes de prosseguir — veja etapa 2.4 caso precise ajustar.
3. Enviar candidatos ação principal
Clique em Enviar candidatos ao SE, selecione a análise encerrada na etapa anterior e confirme. O sistema percorre cada finalista, cria o candidato no SE, anexa o PDF do currículo e registra a nota de aderência. O log de passos fica disponível em cada linha da grade.
4. Acompanhar os resultados
A grade exibe o status de cada envio: Sucesso (candidato criado no SE), Erro (falha na API — clique na linha para ver o detalhe e a mensagem de erro), Parcial (candidato criado mas anexo ou nota com falha) ou Revertido (envio cancelado manualmente).
⚠️ O envio ao SE é irreversível pelo sistema: uma vez criado no Softexpert, o candidato precisa ser excluído manualmente no SE caso seja necessário desfazer. Use o botão Reverter (disponível em alguns modos) com cautela.
💡 Para ver o detalhe técnico de cada envio — incluindo o XML enviado e a resposta recebida da API do SE — clique em qualquer linha da grade de histórico e depois em Ver detalhes do envio.
