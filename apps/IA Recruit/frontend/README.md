# Frontend IA Recruit

Destino dos arquivos visuais do IA Recruit:
- `shell.html`
- dashboard
- curriculos
- vagas
- funcoes
- analisador
- integracoes especificas
- guia de uso do IA Recruit

Os frontends principais ficam nesta pasta. Algumas telas internas ainda
permanecem em `modules/*/frontend` como compatibilidade temporaria.

Scripts especificos do IA Recruit nesta fase:
- `js/sidebar.js`
- `js/tab-manager.js`
- `js/dashboard-vagas.js`
