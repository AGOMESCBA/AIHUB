# Backend IA Administracao

Reservado para servicos administrativos proprios do app IA Administracao.

As rotas globais atuais de empresas, usuarios, sistemas, permissoes, seguranca e
configuracoes ficam em `apps/IAHUB/backend`, porque fazem parte do core da
plataforma.

Este app deve continuar contendo apenas recursos genericos e globais, sem regras
especificas do IA Recruit.
